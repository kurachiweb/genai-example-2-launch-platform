# テストドキュメント索引

テストの方針と実行方法に関する技術資料。記述規則と文書の追加方法は[技術ドキュメント索引](../README.md)に従う。

## 範囲

- テスト方針(テストの種別と命名規約、実行コマンド)
- カバレッジ設定
- IaC定義のテストとCIでのE2Eテストの実行方法、デプロイ後のスモークテスト
- TDDの進め方
- E2Eテストツールの版の更新手順
- 性能の検証(想定規模の合成データ・FCP・GraphQLの応答時間・同時接続の負荷・日次の定期実行の時間の予算・デプロイ中の応答の監視)
- 回帰テストと監査(通しのE2E・定期実行の時刻の制御・全経路のアクセシビリティ・セキュリティの基線・外部サービスを止めた読み取り・指摘の記録)
