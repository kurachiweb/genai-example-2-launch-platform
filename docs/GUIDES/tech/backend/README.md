# バックエンドドキュメント索引

バックエンドのコーディングルールに関する技術資料。記述規則と文書の追加方法は[技術ドキュメント索引](../README.md)に従う。

## 範囲

- アーキテクチャ設計(依存性注入を含む)
- API設計
- ユーザーライフサイクルイベント
- 監査ログの記録
- 外部の通知の冪等な反映
- 定期課金の加入状態と特典の判定
- ハンドル(URLの識別子)の名前空間
- 集約のライフサイクルイベント
- 判定の供給元と保存の処理の登録口
- 期間を限った投票
- 削除しても返信を残すコメントのスレッドと保持期間の後の匿名化
- まとめて送る通知メール
- 単一敗退のブラケット
- 日付の範囲で有効になる購入済みの権利
- 基準日から逆算する日程
- APIキーによる認証と回数の制限
- 集約をまたぐ管理操作の記録
- 投稿の集約と案件の完了・再開
- 利用者のデータのアーカイブの非同期の生成
