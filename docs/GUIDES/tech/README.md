## 記述規則

- 他のプロジェクトへ丸写しできる汎用的な内容だけを書く。
- プロジェクト名、サービス固有の仕様、プロジェクト固有の値(ドメイン・ポート番号・リソース名・絶対パスなど)を書かない。具体的な値が必要な箇所は`<アプリ名>`のようなプレースホルダーで示す。
- 文書間のリンクは相対パスで書く。

## 文書の追加方法

1. 該当するサブディレクトリに、`<3桁の連番>-<内容を表す英小文字とハイフンの名前>.md`(例:`001-naming-conventions.md`)という名前で文書を作る。
2. そのサブディレクトリの索引(`README.md`)の「文書一覧」の表に、文書へのリンクと概要を1行追加する。最初の文書を追加するときは「収録文書はまだ無い。」の記述を消す。
3. 本索引は変更しない。どのサブディレクトリの範囲にも当てはまらない文書を追加する場合に限り、サブディレクトリと索引を新設して上の表に1行追加し、サブディレクトリの一覧を載せている他の文書(リポジトリのREADME・AIエージェント向けの指示ファイルなど)も合わせて更新する。
