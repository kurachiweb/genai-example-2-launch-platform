# 文言・文字数規則

入力欄の文字数上限、UI文言の表記、通知メールの文面規則を定める。文体・語調の方針は[デザイン原則](001-design-principles.md)を参照。

## 入力欄の文字数上限

上限値・必須区分・文字種の制約は対応要件を正とし、本表はその索引である。文字数は書記素(ユーザーが1文字と認識する単位)で数える。全角・半角・絵文字を区別しない。上限はフロントエンドでフォーカスアウト時(UI-004)に検証し、サーバー側でも同じ値で検証する(NFR-SECUR-012)。

## 表記規則

| 対象               | 規則                                                                                 | 例                                                    |
| ------------------ | ------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| 英語固有名詞       | 英語表記のまま。日本語に訳さない                                                     | Upvote、Product of the Week、Ultras、Legend           |
| 日本語と英数字の間 | スペースを入れない                                                                   | 「12票のUpvote」                                      |
| 数値               | 半角。3桁区切りはロケールに従う                                                      | 1,234                                                 |
| 勝敗のスコア       | 「自分対相手」の順で「12対9」。マッチカードは両者のUpvote数を並べる                  | 「12対9で勝利」                                       |
| 週                 | 「2026年第37週(9/7〜9/13)」                                                          | Weekトーナメントの見出し                              |
| ラウンド名         | 1回戦・2回戦・...・準々決勝・準決勝・決勝。残り参加数8で準々決勝、4で準決勝、2で決勝 | 「準決勝」                                            |
| 不戦勝             | 「不戦勝」。相手の退会等による勝利も同じ表記                                         |                                                       |
| 両者敗北           | 「両者敗北(0対0)」                                                                   |                                                       |
| ハンドル           | ユーザーは`@`付き、プロダクトは`@`なし                                               | @KurachiWeb、pitch-notes                              |
| トグル状態         | 現在の状態を示す                                                                     | 「フォロー中」「Upvote済み」                          |
| 破壊的操作の確認   | 対象と結果を明記し、確認ボタンに操作名を入れる                                       | 「プロダクト「Pitch Notes」を削除しますか?」→「削除」 |

## エラーメッセージ

文体は[デザイン原則](001-design-principles.md#文体語調)に従い、技術用語(バリデーション、リクエスト等)は使わない。文中に句点があるか否かによらず、文末には必ず「。」を付ける。

| 状況                               | 文言                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------- |
| ハンドルの重複                     | このハンドルは既に使われています。別の文字列を入力してください。                 |
| ハンドルの文字種違反               | ハンドルは英数字で始め、英数字・ハイフン・アンダースコアのみで入力してください。 |
| 文字数超過                         | ニックネームは25文字以内で入力してください。                                     |
| 外部WebサイトURLの形式違反         | 外部WebサイトURLは"https://"または"http://"から始まるURLを入力してください。     |
| 漏洩パスワード                     | このパスワードは過去に漏洩したことがあります。別のパスワードを設定してください。 |
| ハンドル等と一致するパスワード     | ハンドル・ニックネーム・メールアドレスと同じパスワードは使えません。             |
| メールアドレス重複(ユーザー登録)   | このメールアドレスは登録できません。                                             |
| ログイン失敗                       | メールアドレスまたはパスワードが正しくありません。                               |
| ログイン試行のクールダウン         | ログイン試行が続いたため、しばらく待ってから再度お試しください。                 |
| レート制限(429)                    | 操作が集中しています。しばらく待ってから再度お試しください。                     |
| Turnstile検証失敗                  | 認証に失敗しました。ページを再読み込みして再度お試しください。                   |
| ファイルサイズ超過                 | ロゴは500KB以内の画像を選択してください。                                        |
| ファイル形式違反                   | JPEG・PNG・GIF・WebP・SVGの画像を選択してください。                              |
| Upvote不可(自身のプロダクト)       | 自身のプロダクトとその対戦相手にはUpvoteできません。                             |
| Upvote不可(マッチ外)               | このマッチはUpvoteを受け付けていません。                                         |
| 再ローンチ制限                     | このプロダクトは9月28日以降のローンチ日を選べます。                              |
| 再ローンチ不可(トーナメント参加中) | このプロダクトはWeekトーナメント参加中のため再ローンチできません。               |
| メール未確認                       | この操作にはメールアドレスの確認が必要です。確認メールをご確認ください。         |
| 停止中アカウント                   | このアカウントは現在ご利用いただけません。詳しくはお問い合わせください。         |

### 本文の構成

1. 宛名(ニックネーム)
2. 本文(1〜3段落、です・ます調)
3. 主要な行動へのボタン(マッチを見る、参加費を支払う、ダウンロードなど)
4. 通知種別ごとの配信停止リンク(FR-NOTIF-001〜004のみ)
5. 送信者情報: 事業者名・連絡先・物理的郵送先住所(FR-NOTIF-007)

- メール内の日時(決済期限・キックオフ時刻等)は受信者のタイムゾーンを知り得ないため、UTCのみで表記しタイムゾーンを明記する。例: 「9月15日07:40(UTC)」。リンク先のWebページではブラウザのタイムゾーンで表示する
- 予選勝利の結果通知にはWeekトーナメントの決済期限を明記する
- Weekトーナメント決勝勝利の結果通知にはYearトーナメントの決済期限を明記する
- 配信停止リンクを付ける通知種別と付けない通知種別は[通知メールのオプトアウト](../legal/001-compliance-policy.md#通知メールのオプトアウトlr-005)を正とする
