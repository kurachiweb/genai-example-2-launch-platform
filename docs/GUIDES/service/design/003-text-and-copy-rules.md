# 文言・文字数規則

入力欄の文字数上限、UI文言の表記、通知メールの文面規則を定める。文体・語調の方針は[デザイン原則](001-design-principles.md)を参照。

## 入力欄の文字数上限

文字数は書記素(ユーザーが1文字と認識する単位)で数える。全角・半角・絵文字を区別しない。上限はフロントエンドでフォーカスアウト時に検証し、サーバー側でも同じ値で検証する。

| 入力欄                         | 上限       | 必須 | 文字種の制約                                                   | 対応要件       |
| ------------------------------ | ---------- | ---- | -------------------------------------------------------------- | -------------- |
| ユーザーのニックネーム         | 25文字     | ◯    | —                                                              | FR-USER-001    |
| ユーザーのハンドル             | 25文字     | ◯    | 英数字で始まり、英数字・`-`・`_`のみ。大文字小文字を区別しない | FR-UPROF-003   |
| ヘッドライン                   | 50文字     |      | —                                                              | FR-UPROF-001   |
| 自己紹介                       | 上限なし   |      | マークダウン(見出し1・画像・Raw HTMLは文字列として描画)         | FR-UPROF-004   |
| 外部WebサイトURLの名前         | 25文字     |      | URLと対で入力                                                  | FR-UPROF-008   |
| プロダクト名称                 | 50文字     | ◯    | —                                                              | FR-PRDCT-001   |
| プロダクトのタグライン         | 100文字    | ◯    | —                                                              | FR-PRDCT-001   |
| プロダクトのハンドル           | 50文字     | ◯    | ユーザーのハンドルと同じ                                       | FR-PRDCT-007   |
| プロダクト説明文               | 上限なし   | ◯    | マークダウン                                                   | FR-PRDCT-003   |
| コメント                       | 上限なし   | ◯    | マークダウン                                                   | FR-COMNT-001   |
| 通報理由                       | 1,000文字  | ◯    | プレーンテキスト                                               | FR-REPOT-003   |
| 問い合わせメッセージ           | 5,000文字  | ◯    | プレーンテキスト                                               | FR-INQRY-001   |
| 問い合わせのニックネーム(未ログイン) | 25文字 | ◯    | —                                                              | FR-INQRY-001   |
| キーワード検索                 | 50文字     |      | —                                                              | FR-DIR-006、FR-HELP-004 |
| APIキーの名前                  | 50文字     | ◯    | —                                                              | FR-PAPI-001    |
| パスワード                     | 8〜128文字 | ◯    | 文字種の組み合わせは要求しない                                 | NFR-SECUR-025  |
| ヘルプ記事のタイトル・サブタイトル | 各100文字 | ◯  | —                                                              | FR-ADMAG-009   |
| ヘルプ記事のハンドル           | 50文字     | ◯    | プロダクトのハンドルと同じ                                     | FR-ADMAG-013   |
| 管理者のニックネーム           | 25文字     | ◯    | —                                                              | FR-ADMAC-007   |
| 管理者の肩書き                 | 50文字     |      | —                                                              | FR-ADMAC-007   |
| 法務文書の変更概要             | 200文字    | ◯    | —                                                              | FR-ADMAG-007   |
| 管理者操作の理由(停止・非公開化等) | 500文字 | ◯    | ユーザーや管理者の個人情報を含めない旨を入力欄に注記           | FR-ADMAG-001   |
| カテゴリ名(各種マスタ)         | 30文字     | ◯    | —                                                              | FR-ADMCF-006等 |

要件定義書に上限のない項目(通報理由・問い合わせメッセージ・URL名・APIキー名・変更概要・理由・カテゴリ名)の上限は本書が定める。

## 表記規則

| 対象                                 | 規則                                                                       | 例                                             |
| ------------------------------------ | -------------------------------------------------------------------------- | ---------------------------------------------- |
| 英語固有名詞                         | 英語表記のまま。日本語に訳さない                                           | Upvote、Product of the Week、Ultras、Legend    |
| 日本語と英数字の間                   | スペースを入れない                                                         | 「12票のUpvote」                               |
| 数値                                 | 半角。3桁区切りはロケールに従う                                            | 1,234                                          |
| 勝敗のスコア                         | 「自分対相手」の順で「12対9」。マッチカードは両者のUpvote数を並べる         | 「12対9で勝利」                                |
| 週                                   | 「2026年第37週(9/7〜9/13)」                                                | Weekトーナメントの見出し                       |
| ラウンド名                           | 1回戦・2回戦・...・準々決勝・準決勝・決勝。残り参加数8で準々決勝、4で準決勝、2で決勝 | 「準決勝」                                 |
| 不戦勝                               | 「不戦勝」。相手の退会等による勝利も同じ表記                               |                                                |
| 両者敗北                             | 「両者敗北(0対0)」                                                         |                                                |
| ハンドル                             | ユーザーは`@`付き、プロダクトは`@`なし                                     | @kurachi_dev、pitch-notes                      |
| ボタンの動詞                         | 体言止め。「〜する」を付けない                                             | 「ローンチを予約」「フォロー」「Upvote」       |
| トグル状態                           | 現在の状態を示す                                                           | 「フォロー中」「Upvote済み」                   |
| 破壊的操作の確認                     | 対象と結果を明記し、確認ボタンに操作名を入れる                             | 「プロダクト「Pitch Notes」を削除しますか?」→「削除」 |

## エラーメッセージ

原因と対処を1文で、です・ます調で書く。技術用語(バリデーション、リクエスト等)は使わない。

| 状況                                   | 文言                                                                       |
| -------------------------------------- | -------------------------------------------------------------------------- |
| ハンドルの重複                         | このハンドルは既に使われています。別の文字列を入力してください             |
| ハンドルの文字種違反                   | ハンドルは英数字で始め、英数字・ハイフン・アンダースコアのみで入力してください |
| 文字数超過                             | ニックネームは25文字以内で入力してください                                 |
| 漏洩パスワード                         | このパスワードは過去に漏洩したことがあります。別のパスワードを設定してください |
| ハンドル等と一致するパスワード         | ハンドル・ニックネーム・メールアドレスと同じパスワードは使えません         |
| メールアドレス重複(登録・変更)         | このメールアドレスは登録できません                                         |
| ログイン失敗                           | メールアドレスまたはパスワードが正しくありません                           |
| ログイン試行のクールダウン             | ログイン試行が続いたため、しばらく待ってから再度お試しください             |
| レート制限(429)                        | 操作が集中しています。しばらく待ってから再度お試しください                 |
| Turnstile検証失敗                      | 認証に失敗しました。ページを再読み込みして再度お試しください               |
| ファイルサイズ超過                     | ロゴは500KB以内の画像を選択してください                                    |
| ファイル形式違反                       | JPEG・PNG・GIF・WebP・AVIF・SVGの画像を選択してください                    |
| Upvote不可(自身のプロダクト)           | 自身のプロダクトとその対戦相手にはUpvoteできません                         |
| Upvote不可(マッチ外)                   | このマッチはUpvoteを受け付けていません                                     |
| 再ローンチ制限                         | このプロダクトは9月28日以降のローンチ日を選べます                          |
| メール未確認                           | この操作にはメールアドレスの確認が必要です。確認メールをご確認ください     |
| 停止中アカウント                       | このアカウントは現在ご利用いただけません。詳しくはお問い合わせください     |

メールアドレスの重複・パスワードリセット・メールアドレス変更では、対象アカウントの有無を推測させない同一の文言を返す(NFR-SECUR-041)。

## 通知メール

### 件名

接頭辞は付けず、件名のみとする。プロダクト名と対戦相手を含め、件名だけで内容が分かるようにする。

| 通知種別                       | 件名例                                                       |
| ------------------------------ | ------------------------------------------------------------ |
| マッチ開始予告(FR-NOTIF-001)   | 明日キックオフ: Pitch Notes vs Tactics Board                 |
| 勝敗結果(FR-NOTIF-002)         | フルタイム: Pitch Notesが12対9で勝利                         |
| 勝敗結果+翌日予告の統合        | フルタイム: Pitch Notesが勝利、明日は準決勝                  |
| フォロー中ユーザーのマッチ開催(FR-NOTIF-003) | Kurachiの「Pitch Notes」が本日キックオフ       |
| 同上(同日複数の集約)           | フォロー中の3プロダクトが本日キックオフ                      |
| 受賞結果(FR-NOTIF-004)         | Kurachiの「Pitch Notes」がProduct of the Weekを受賞          |
| データエクスポート完了         | データエクスポートの準備ができました                         |
| データエクスポート失敗         | データエクスポートに失敗しました                             |
| 問い合わせへの返信             | お問い合わせに返信がありました                               |
| 管理者による停止・非公開化     | コンテンツの公開が停止されました                             |

### 本文の構成

1. 宛名(ニックネーム)
2. 本文(1〜3段落、です・ます調)
3. 主要な行動へのボタン(マッチを見る、参加費を支払う、ダウンロードなど)
4. 通知種別ごとの配信停止リンク(FR-NOTIF-001〜004のみ)
5. 送信者情報: 事業者名・連絡先・物理的郵送先住所(FR-NOTIF-007)

- メール内の日時(決済期限・キックオフ時刻等)は受信者のタイムゾーンを知り得ないため、UTCのみで表記しタイムゾーンを明記する。例: 「9月15日 07:40 (UTC)」。リンク先のWebページではブラウザのタイムゾーンで表示する
- 予選勝利の結果通知にはWeekトーナメントの決済期限を明記する
- 認証系メール(メールアドレス確認・パスワードリセット等)には配信停止リンクを付けない(取引に必要なメールのため)
