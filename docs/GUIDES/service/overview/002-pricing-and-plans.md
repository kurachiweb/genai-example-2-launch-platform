# 料金及びプラン体系

本サービスの課金項目と、それぞれの特典・免除条件・解約時の扱いを整理する。
全ての価格はStripeのダッシュボード上で設定し、通貨はUSDに統一する(I18N-003)。本書に記載する金額は初期想定の参考値であり、正はStripeダッシュボードの設定値である。

## Ultrasプラン(月額有料プラン)

### 特典

| 特典                             | 未加入ユーザー                       | Ultras加入中ユーザー                   |
| -------------------------------- | ------------------------------------ | -------------------------------------- |
| 予選敗北後の再ローンチ間隔       | 直近ローンチ開始から7日経過後        | 直近ローンチ開始から2日経過後          |
| Weekトーナメント参加費           | 決済期限までに都度決済が必要         | 免除                                   |
| Yearトーナメント参加費           | 決済期限までに都度決済が必要         | 免除                                   |

再ローンチ間隔の詳細は[再ローンチ規則](006-relaunch-rules.md)を参照。

### 加入・解約・失効

- 加入前に価格を表示し、Stripe Checkout Sessions APIで発行したセッションに紐付くPayment Elementで決済する
- 解約した場合、基準時刻(UTC-08:00)で当該課金期間の末日まで特典を継続提供する
- 退会した場合、システムが定期課金を解約する
- 定期課金の支払い失敗がStripeのリトライ後もなお解消しない場合、Webhookで受信したサブスクリプションステータスをもとに特典提供を終了する
- ユーザーは自身の現在のプラン状態を確認できる
- 未加入ユーザーへのUltras導線表示は、管理者が機能フラグで切り替えられる(FR-ADMCF-018)。フラグをオフにしても加入済みユーザーの特典には影響しない

### トーナメント参加費免除の判定時点

免除の判定は各トーナメントの決済期限時点で行う。決済期限までにUltrasに加入していれば参加資格を得る。期限後に加入しても、その週(年)のトーナメントには参加できない。
逆に、決済期限時点でUltras加入中であれば、その後トーナメント期間中に解約しても参加資格は失われない。

## トーナメント参加費(都度決済)

| 項目         | Weekトーナメント                                 | Yearトーナメント                                   |
| ------------ | ------------------------------------------------ | -------------------------------------------------- |
| 対象         | 予選に勝利したローンチ                           | Product of the Week受賞プロダクト                  |
| 決済期限     | ローンチ日を含む週の翌週月曜日23:40              | Yearトーナメント決勝日の6日前(月曜日)23:40         |
| 免除         | 決済期限時点でUltras加入中                       | 決済期限時点でUltras加入中                         |
| 未決済の場合 | 参加資格なし(ディレクトリ掲載は維持)             | 参加資格なし(Product of the Week賞は維持)          |

参加費は「参加資格」に対する対価であり、トーナメントの試合結果や不戦勝・不戦敗による返金は行わない。

## スポンサー広告(都度決済)

- ユーザーは自身が過去にローンチしたプロダクトを1つ選び、ティア(Silver/Gold/Legend)と掲載期間を申し込む
- 掲載期間は基準時刻で今日以降を1日単位で選択する。価格は「日数×ティアの1日単価」で、決済セッション作成時に日数を数量として指定する
- 決済完了後、選択した期間中に広告スペースへ表示する。ティアによる表示位置・サイズの差は[ページ構成](../design/002-page-layouts.md)を参照
- 管理者が理由付きで掲載を強制終了した場合、返金はStripeダッシュボード上で管理者が手動判断する

## 返金・チャージバック

- 返金はシステム上の機能としては提供せず、管理者がStripeダッシュボード上で手動実行する。返金イベントはWebhookで受信し、ユーザーの決済履歴へ反映する
- チャージバック(dispute)が発生しても、Ultras特典やトーナメント参加資格、スポンサー広告掲載を自動的には停止・剥奪・復元しない。対応が必要な場合は管理者機能(ユーザー停止、広告の強制終了等)で個別に対応する
- チャージバックへの証拠提出(representment)はStripeダッシュボード上で管理者が直接行う

## 決済履歴

ユーザーは自身の決済履歴(都度決済・定期課金・返金・チャージバック)を確認できる。決済履歴の保持期間は7年(DR-013)である。
