# 料金及びプラン体系

本サービスの課金項目と、それぞれの特典・免除条件を整理する。

全ての価格はStripeのダッシュボード上で設定し、通貨はUSDに統一する(I18N-003)。

価格は消費税・海外の付加価値税等を含む税込総額であり、StripeのPriceの`tax_behavior`を`inclusive`に設定した上でStripe Taxにより購入者居住地に応じた税額を算出する(LR-009)。

利用できる決済手段はFR-PYMNT-001を正とする。

## Ultrasプラン(月額有料プラン)

特典は予選敗北後の再ローンチ間隔の短縮(FR-RELCH-003、[再ローンチ規則](006-relaunch-rules.md))とトーナメント参加費の免除(FR-PPLAN-005)の2つである。加入・解約・退会時・停止時・支払い失敗時の扱い及び支払い方法の更新はFR-PPLAN-001〜010を正とする。

- 未加入ユーザーへのUltras導線表示は管理者が機能フラグで切り替える(FR-ADMCF-018)。フラグをオフにしても加入済みユーザーの特典には影響しない

### 状態ごとの特典の適用

特典を適用するかは、Ultrasプランの状態で決まる。状態名は[データエクスポート](../features/001-user-data-export.md#accountjson)の`plan.status`と同じである。

| 状態                             | 参加費免除・再ローンチ間隔の短縮 | 根拠                       |
| -------------------------------- | -------------------------------- | -------------------------- |
| `active`(有効)                   | 適用する                         | FR-PPLAN-005、FR-RELCH-003 |
| `past_due`(支払い失敗の再試行中) | 適用する                         | FR-PPLAN-006               |
| `canceled`(解約済みで課金期間内) | 適用する                         | FR-PPLAN-003               |
| `ended`(終了)                    | 適用しない                       | FR-PPLAN-003、FR-PPLAN-006 |

- 公開プロフィールでUltras加入中であることを示す表示(FR-UPROF-013)も、この表の「適用する」状態の間に限る
- 再試行の回数と期間はStripeダッシュボードの設定に従う。再試行後の処理は、復帰のない`ended`に対応する「サブスクリプションをキャンセルする」とする

### トーナメント参加費の免除条件

免除の判定は、勝利時点とUltras加入時点の2つの時点で行う。勝利時点は、マッチの勝者が確定した時点を指す。

- 勝利時点でUltrasプランに加入中(有効・支払い失敗の再試行中・解約済みで課金期間内のいずれか、[状態ごとの特典の適用](#状態ごとの特典の適用))であれば、即座に参加資格を得る
  - 予選勝利時点
  - Week優勝時点
- 勝利時点より後、決済期限より前にUltrasプランに加入すれば、その加入時点で参加資格を得る
  - 加入時に未完了の参加費の決済セッションが残る場合の扱いはFR-PPLAN-007を正とする

既に得た参加資格は、Ultrasプランを解約しても、支払い失敗により特典が終了しても失われない。ただし組み合わせ決定前にプロダクトを削除した場合や、退会によりプロダクトが論理削除された場合は、決済で得たか免除で得たかにかかわらず失う(FR-TOURW-021・FR-TOURY-021)。逆に期限後にUltrasに加入しても、その週(年)のトーナメントへの参加資格は得られない。

## トーナメント参加費(都度決済)

対象・決済期限・免除はFR-TOURW-002〜003(Weekへの参加)、FR-TOURY-002〜003(Yearへの参加)を正とする。未決済の場合は参加資格を得ないだけで、予選勝利によるディレクトリ掲載やProduct of the Week賞は維持する。

参加費は「参加資格」に対する対価であり、トーナメントの試合結果や不戦勝・不戦敗による返金は行わない。一方、組み合わせ決定前にプロダクトの削除や退会により参加資格を失った場合(FR-TOURW-021・FR-TOURY-021)は、決済した参加費を自動で全額返金する(FR-PYMNT-009、[返金ポリシー](../legal/004-legal-notice-outline.md#返金ポリシー))。決済が組み合わせ決定までに参加資格へ反映できなかった場合も、同様に自動で全額返金する(FR-PYMNT-012)。

### UI表示において決済期限を35分早める理由

Stripeの決済セッションは予選(Week優勝)勝利時点ではなく投稿ユーザーが決済ボタンを押した時点で都度作成する。この時セッションの決済期限(`expires_at`)は既定値(作成から24時間)とFR-TOURW-002・FR-TOURY-002の決済期限(UTC-08:00の23時35分)の早い方とする。

Stripeでは`expires_at`を作成時点から30分〜24時間の範囲でしか指定できない([Stripe API](https://docs.stripe.com/api/checkout/sessions/create))ため、決済セッションの作成受付は決済期限の35分前である23:00までとし、以降の作成要求はサーバー側で拒否する。利用者側UIにも、この受付期限と同じ23:00を決済期限として表示する。

### 決済期限を組み合わせ決定よりも10分早める理由

決済完了から23時45分の組み合わせ決定までに少なくとも10分の猶予を持たせ、StripeのWebhookと決済ランディングページのいずれでも反映されなかった決済を、組み合わせ決定前にStripe APIと突合できるようにするためである(FR-PYMNT-008・FR-PYMNT-011、[同時刻に走る処理の順序](007-daily-timeline.md#同時刻に走る処理の順序))。

## スポンサー広告(都度決済)

申し込み・掲載期間・価格計算はFR-SPONS-001〜005・FR-PYMNT-002を正とする。ティアによる表示位置・サイズの差は[ページ構成](../design/002-page-layouts.md#スポンサー広告スペース)、管理者が掲載を強制終了した場合(FR-ADMUG-023)及びプロダクトの非公開化・削除等で表示が止まる場合(FR-SPONS-016)の返金は[返金ポリシー](../legal/004-legal-notice-outline.md#返金ポリシー)を参照。

## 返金・チャージバック・決済履歴

返金の運用は[返金ポリシー](../legal/004-legal-notice-outline.md#返金ポリシー)、チャージバック時の扱いは要件定義書「決済機能」節の前書きとFR-PYMNT-006〜007、決済履歴の表示と保持期間はFR-PYMNT-004・DR-013を正とする。
