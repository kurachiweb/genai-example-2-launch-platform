# Product of the Year決定トーナメント規則

年間のProduct of the Week受賞プロダクト同士が、シングルエリミネーション方式でProduct of the Yearを決めるトーナメントである。本書では「トーナメント」と書けばYearトーナメントを指す。
組み合わせ方式はWeekトーナメントと共通部分が多いため、差分を中心に記す。共通部分は[Weekトーナメント規則](004-week-tournament-rules.md)を参照。
時刻は全て基準時刻(UTC-08:00)である。

## 決勝日

| 項目               | 規則                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------- |
| 設定者             | 最上位管理者                                                                                                  |
| 選択できる日       | 対象年内の日曜日。現在時刻の8日後より前は選べない                                                             |
| 未設定時の既定値   | 対象年5月の最終日曜日                                                                                         |
| 前年との間隔       | 前年の決勝日が設定済みなら、前年決勝日の64週間後以降は選べない(参加数を64以下に抑えるため)                   |
| 変更期限           | 決勝開始(決勝日0:00)の7日前以降は変更できない                                                                 |

決勝日はサッカー熱が最高潮となる欧州リーグ最終節付近(イングランドのプレミアリーグ最終節実施日付近)に合わせて設定する運用とする。

## 参加資格

- 対象は「前回のトーナメントの決済期限日当日」から「今回のトーナメントの決済期限日の前日」までにWeekトーナメントで優勝したプロダクト
- 決済期限は決勝日の6日前(月曜日)23:40
- 投稿者が決済期限までにトーナメント参加費を決済するか、決済期限時点でUltrasに加入していれば参加資格を得る

Product of the Week受賞後は次回Yearトーナメント決勝日まで再ローンチできないため、1つのプロダクトが同一年のYearトーナメントに複数の資格で参加することはない。

## 日程

ラウンド数は参加数Nに応じて決まり、決勝は必ず決勝日に行う。1回戦の実施日は決勝日から逆算する(FR-TOURY-007)。

| 参加数N | 1回戦の実施日  | ラウンド数 |
| ------- | -------------- | ---------- |
| 2       | 決勝日(日曜日) | 1          |
| 3〜4    | 1日前(土曜日)  | 2          |
| 5〜8    | 2日前(金曜日)  | 3          |
| 9〜16   | 3日前(木曜日)  | 4          |
| 17〜32  | 4日前(水曜日)  | 5          |
| 33〜64  | 5日前(火曜日)  | 6          |

| 時点                    | 事象                                                                 |
| ----------------------- | -------------------------------------------------------------------- |
| 決勝日の6日前(月)23:40  | 決済期限                                                             |
| 決勝日の6日前(月)23:45  | 組み合わせ決定、1回戦両投稿者へマッチ開始予告メール                  |
| 1回戦実施日 0:00〜23:40 | 1回戦(参加数により火曜日〜日曜日のいずれか)                          |
| 以降毎日 0:00〜23:40    | 勝者同士で次ラウンド                                                 |
| 決勝日(日)23:40         | 決勝終了。優勝プロダクトにProduct of the Year賞、フォロワーへ受賞通知 |

組み合わせ決定から1回戦までに空白日が生じる場合(N≤32)、その間はマッチが行われない。空白日中もWeekトーナメントや予選は通常通り行われる。

## 組み合わせ決定の手順

### 1. シード数の決定

Weekトーナメントと同じ考え方だが、2回戦の参加数Pに上限32を設ける。

- P = N以下で最大の2の冪。ただし最大32
- シード数S = 2P − N(Nが2の冪ならS = 0)
- N = 33〜64のとき、Pは32となり1回戦から全プロダクトが対戦するか、多数がシードとなる

| N   | P   | S(シード数) | 1回戦マッチ数 | 2回戦参加数 | 1回戦実施日 |
| --- | --- | ----------- | ------------- | ----------- | ----------- |
| 1   | —   | —           | —             | —           | 即時受賞    |
| 2   | 2   | 0           | 1             | —           | 決勝日      |
| 3   | 2   | 1           | 1             | 2           | 1日前       |
| 13  | 8   | 3           | 5             | 8           | 3日前       |
| 20  | 16  | 12          | 4             | 16          | 4日前       |
| 32  | 32  | 0           | 16            | 16          | 4日前       |
| 33  | 32  | 31          | 1             | 32          | 5日前       |
| 40  | 32  | 24          | 8             | 32          | 5日前       |
| 64  | 32  | 0           | 32            | 32          | 5日前       |

### 2. シードの選出

Weekトーナメントと同じ。予選勝利時のUpvote数が多い順 → 最終Upvote時刻が早い順 → ローンチのID(ULID)昇順で並べ、上位S個をシードとする。ここでの「予選」は、Product of the Week受賞に至ったローンチの予選である。

### 3. 非シードの1回戦組み合わせ

非シードをローンチ日が早い順に並べ、隣接する2個ずつを対戦相手とする。Yearトーナメントの参加プロダクトは異なる週のWeek優勝者であるためローンチ日は重複しないが、実装上の安全策として同日の場合はWeekトーナメントと同じタイブレーク(予選勝利時Upvote数 → 最終Upvote時刻 → ULID)を適用する。

### 4. 2回戦以降

Weekトーナメントと同じ。2回戦は「シードをシード順 → 1回戦勝者をマッチ順」に並べて隣接ペア、3回戦以降は固定ブラケットとする。

## 勝敗判定・不戦勝・参加数が少ない場合

Weekトーナメントと同一の規則を適用する。

- Upvote数が多い方が勝者。同数で1以上なら最終Upvote時刻が早い方。両者0なら両者敗北
- 隣接マッチが両者敗北、または対戦相手の退会・停止・非公開化により対戦相手がいない場合、マッチ開始時点で不戦勝として次ラウンドへ進む
- 同ラウンドの全プロダクトが敗北した場合、トーナメントを終了し賞は授与しない
- 参加数が1の場合、組み合わせ決定時(決勝日の6日前23:45)に即時受賞
- 参加数が0の場合、トーナメントは開催しない

## Weekトーナメントとの差分まとめ

| 項目                     | Weekトーナメント                          | Yearトーナメント                                    |
| ------------------------ | ----------------------------------------- | --------------------------------------------------- |
| 対象                     | 同一週の予選勝利ローンチ                  | 対象期間内のWeek優勝プロダクト                      |
| 参加数上限               | なし(129以上で翌週と重複)                 | 64(決勝日設定の制約により保証)                      |
| 2回戦参加数Pの上限       | なし                                      | 32                                                  |
| 組み合わせ決定           | 翌週月曜日23:45                           | 決勝日の6日前(月曜日)23:45                          |
| 1回戦                    | 組み合わせ決定の翌日(火曜日)              | 参加数に応じて決勝日から逆算                        |
| 非シードの並び順         | ローンチ日 → 予選勝利時Upvote数 → ...     | ローンチ日(重複しない前提、同日時は同じタイブレーク) |
| 受賞後の再ローンチ制限   | 次回Year決勝日以前は禁止                  | 制限なし(Week受賞時の制限は継続)                    |
