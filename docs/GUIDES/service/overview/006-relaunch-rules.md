# 再ローンチ規則

一度ローンチしたプロダクトは、同じプロダクトとして何度でも再ローンチできる(FR-RELCH-001)。頻繁な再ローンチはハングリー精神の表れとして歓迎するが、勝者の独占や連投を防ぐために間隔制限を設ける。
制限そのものはFR-RELCH-002〜006を正とし、本書は解釈・計算例・意図を補う。時刻は全て基準時刻(UTC-08:00)である。

## 間隔制限の解釈

| 直近ローンチの結果             | 対応要件         | 制限の種類                                       |
| ------------------------------ | ---------------- | ------------------------------------------------ |
| 予選敗北(0対0の両者敗北を含む) | FR-RELCH-002/003 | 選択できるローンチ日への制約                     |
| 予選勝利(不戦勝を含む)         | FR-RELCH-004     | 選択できるローンチ日への制約(Ultrasでも短縮なし) |
| Weekトーナメント参加中         | FR-RELCH-006     | 選択日によらず登録・編集リクエスト自体を拒否     |
| Weekトーナメント優勝           | FR-RELCH-005     | 選択できるローンチ日への制約                     |

- 「ローンチ開始時間」はローンチ日の0:00である
- 全ての制限は「直近のローンチ」を基準にする。過去のローンチ結果は影響しない
- 「選択できるローンチ日への制約」は該当する日をローンチ日の選択肢から除外し、制限を満たさない登録・編集リクエストはサーバー側でも拒否する。FR-PRDCT-002の翌日以降制約と併せて適用する
- FR-RELCH-006の対象期間は、参加資格を得た時点から敗退または当該トーナメント終了までである

## Ultras加入状態の判定時点

再ローンチの間隔は、ローンチ日を登録・編集する時点のUltras加入状態で判定する。登録後に解約しても予約済みのローンチは維持する。

## 計算例

### 予選敗北 → 再ローンチ

2026-09-07(月)にローンチして予選に敗北した場合。

| 加入状態     | 選択可能な最も早いローンチ日 | 根拠                          |
| ------------ | ---------------------------- | ----------------------------- |
| 未加入       | 2026-09-14(月)               | 09-07 0:00 + 7日 = 09-14 0:00 |
| Ultras加入中 | 2026-09-09(水)               | 09-07 0:00 + 2日 = 09-09 0:00 |

Ultras加入者は予選敗北の翌日23:40までに登録すれば、敗北から2日後にすぐ再挑戦できる。

### 予選勝利 → Weekトーナメント敗退 → 再ローンチ

2026-09-07(月)にローンチして予選に勝利し、2026-09-16(水)のWeekトーナメント2回戦で敗退した場合。

| 時点               | 再ローンチ登録                                                                   |
| ------------------ | -------------------------------------------------------------------------------- |
| 09-07〜09-16 23:40 | 不可。トーナメント参加中のため、選択日によらず登録リクエストを拒否(FR-RELCH-006) |
| 09-16 23:40以降    | 可。21日制限により選べるローンチ日は2026-09-28(月)以降                           |

Weekトーナメントに参加しなかった(決済しなかった)場合も、21日制限により2026-09-28以降となる。

### Weekトーナメント優勝 → 再ローンチ

2026-09-18(金)にWeekトーナメントで優勝した場合、次回Yearトーナメント決済期限日(例: 決勝日が2027年5月の最終日曜日(2027-05-30、管理者が設定)なら、その6日前の2027-05-24(月)23:35)より後の日のみ選択できる。

## 予約済みローンチの扱い

登録時点で適法だった再ローンチの予約は既得権として維持する。

| 事象                                                             | 予約の扱い                                   |
| ---------------------------------------------------------------- | -------------------------------------------- |
| 管理者がYearトーナメント決勝日を変更し、予約日が禁止期間に入った | 維持する                                     |
| 予約後にUltrasを解約した                                         | 維持する                                     |
| 予約日の前日23:45にペアリングされた                              | FR-PRDCT-012により変更・論理削除不可         |
| 管理者がプロダクトを非公開化した                                 | FR-ADMUG-008により未開始のローンチ予定を取消 |
| 投稿者が退会した                                                 | FR-PRDCT-013によりプロダクトと共に論理削除   |

## 制限の意図

| 制限                             | 意図                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------- |
| 敗北後7日(Ultrasは2日)           | 敗北直後の再投稿で予選枠を埋め尽くすことを防ぎつつ、改善して再挑戦するPDCAを促す             |
| 勝利後21日                       | 勝利プロダクトが繰り返しディレクトリ上位を占めることを防ぎ、他のプロダクトに勝利の機会を回す |
| Weekトーナメント参加中は登録不可 | トーナメント中のプロダクトの状態変更を防ぐ                                                   |
| Week優勝後はYear決済期限まで禁止 | Yearトーナメントの参加資格を1プロダクト1つに保ち、受賞ローンチの記録を固定する               |
