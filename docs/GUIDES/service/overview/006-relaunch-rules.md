# 再ローンチ規則

一度ローンチしたプロダクトは、同じプロダクトとして何度でも再ローンチできる。頻繁な再ローンチはハングリー精神の表れとして歓迎するが、勝者の独占や連投を防ぐために以下の間隔制限を設ける。
時刻は全て基準時刻(UTC-08:00)である。

## 間隔制限の一覧

| 直近ローンチの結果               | 有料プラン未加入                          | Ultras加入中                              | 対応要件     |
| -------------------------------- | ----------------------------------------- | ----------------------------------------- | ------------ |
| 予選敗北(0対0の両者敗北を含む)   | ローンチ開始時間から7日経過後             | ローンチ開始時間から2日経過後             | FR-RELCH-002/003 |
| 予選勝利(不戦勝を含む)           | ローンチ開始時間から21日経過後            | 同左(短縮なし)                            | FR-RELCH-004 |
| Weekトーナメント参加中           | 敗退またはトーナメント終了まで登録不可    | 同左                                      | —            |
| Weekトーナメント優勝             | 次回Yearトーナメント決勝日以前は禁止      | 同左                                      | FR-RELCH-005 |

- 「ローンチ開始時間」はローンチ日の0:00である
- 全ての制限は「直近のローンチ」を基準にする。過去のローンチ結果は影響しない
- 上記に加え、[予選ルール](003-qualifier-rules.md)のローンチ日選択制約(翌日以降、23:40以降は翌々日以降)も適用する
- 制限に該当する日はローンチ日の選択肢から除外される。制限を満たさない登録・編集リクエストはサーバー側でも拒否する

## Ultras加入状態の判定時点

再ローンチの間隔は、ローンチ日を登録・編集する時点のUltras加入状態で判定する。登録後に解約しても予約済みのローンチは維持する。

## 計算例

### 予選敗北 → 再ローンチ

2026-09-07(月)にローンチして予選に敗北した場合。

| 加入状態     | 選択可能な最も早いローンチ日 | 根拠                              |
| ------------ | ---------------------------- | --------------------------------- |
| 未加入       | 2026-09-14(月)               | 09-07 0:00 + 7日 = 09-14 0:00     |
| Ultras加入中 | 2026-09-09(水)               | 09-07 0:00 + 2日 = 09-09 0:00     |

Ultras加入者は予選敗北の翌日23:40までに登録すれば、敗北から2日後にすぐ再挑戦できる。

### 予選勝利 → Weekトーナメント敗退 → 再ローンチ

2026-09-07(月)にローンチして予選に勝利し、2026-09-16(水)のWeekトーナメント2回戦で敗退した場合。

| 時点                    | 再ローンチ登録                                           |
| ----------------------- | -------------------------------------------------------- |
| 09-07〜09-16 23:40      | 不可(21日制限、かつトーナメント参加中)                   |
| 09-16 23:40以降         | 可。選べるローンチ日は2026-09-28(月)以降                 |

Weekトーナメントに参加しなかった(決済しなかった)場合も、21日制限により2026-09-28以降となる。

### Weekトーナメント優勝 → 再ローンチ

2026-09-18(金)にWeekトーナメントで優勝した場合、次回Yearトーナメント決勝日(例: 2027年5月の最終日曜日、管理者が設定)より後の日のみ選択できる。

## 予約済みローンチの扱い

登録時点で適法だった再ローンチの予約は既得権として維持する。

| 事象                                                                       | 予約の扱い                                              |
| -------------------------------------------------------------------------- | ------------------------------------------------------- |
| 管理者がYearトーナメント決勝日を変更し、予約日が禁止期間に入った           | 維持する                                                |
| 予約後にUltrasを解約した                                                   | 維持する                                                |
| 予約日の前日23:45にペアリングされた                                        | 以降ローンチ日・カテゴリの変更と論理削除は不可           |
| 管理者がプロダクトを非公開化した                                           | 未開始のローンチ予定を取り消す(FR-ADMUG-008)             |
| 投稿者が退会した                                                           | プロダクトと共にローンチを論理削除する                   |

## 制限の意図

| 制限                               | 意図                                                                                                     |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 敗北後7日(Ultrasは2日)             | 敗北直後の再投稿で予選枠を埋め尽くすことを防ぎつつ、改善して再挑戦するPDCAを促す                          |
| 勝利後21日                         | 勝利プロダクトが繰り返しディレクトリ上位を占めることを防ぎ、他のプロダクトに勝利の機会を回す              |
| Weekトーナメント参加中は登録不可   | トーナメント中のプロダクトの状態変更を防ぐ                                                               |
| Week優勝後はYear決勝まで禁止       | Yearトーナメントの参加資格を1プロダクト1つに保ち、受賞ローンチの記録を固定する                           |
