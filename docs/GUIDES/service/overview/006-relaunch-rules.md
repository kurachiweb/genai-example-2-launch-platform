# 再ローンチ規則

一度ローンチしたプロダクトは、同じプロダクトとして何度でも再ローンチできる(FR-RELCH-001)。頻繁な再ローンチはハングリー精神の表れとして歓迎するが、勝者の独占・連投や、同一プロダクトによるトーナメント参加資格の重複を防ぐために間隔制限を設ける。
制限そのものはFR-RELCH-002〜004を正とし、本書は解釈・計算例・意図を補う。時刻は全て基準時刻(UTC-08:00)である。

## 間隔制限の解釈

| 直近ローンチの結果                                                                      | 対応要件         | 制限の種類                                               |
| --------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------- |
| 予選敗北(0対0の両者敗北を含む)                                                          | FR-RELCH-002/003 | 選択できるローンチ日への制約                             |
| 予選勝利、次回Product of the Yearトーナメントへの参加可能性が残っている間(不戦勝を含む) | FR-RELCH-004     | 選択できるローンチ日への制約(Ultras加入でも早期解除なし) |

- 「ローンチ開始時間」はローンチ日の0:00である
- 全ての制限は「直近のローンチ」を基準にする。過去のローンチ結果は影響しない
- 「選択できるローンチ日への制約」は該当する日をローンチ日の選択肢から除外し、制限を満たさない登録・編集リクエストはサーバー側でも拒否する。FR-PRDCT-002の翌日以降制約と併せて適用する
- FR-RELCH-004の「参加可能性が残っている間」がいつ終了するかはFR-RELCH-004本文を参照。ただしYearトーナメントへの参加資格を得た場合、Year決済期限日(FR-TOURY-002)の到来自体が制約対象の日を無くすため、その後の勝敗を待たず同時点で再ローンチできるようになる点に注意する

## Ultras加入状態の判定時点

再ローンチの間隔は、ローンチ日を登録・編集する時点のUltras加入状態で判定する。登録後に解約しても予約済みのローンチは維持する。

## 計算例

### 予選敗北 → 再ローンチ

2026-09-07(月)にローンチして予選に敗北した場合。

| 加入状態     | 選択可能な最も早いローンチ日 | 根拠                          |
| ------------ | ---------------------------- | ----------------------------- |
| 未加入       | 2026-09-14(月)               | 09-07 0:00 + 7日 = 09-14 0:00 |
| Ultras加入中 | 2026-09-09(水)               | 09-07 0:00 + 2日 = 09-09 0:00 |

Ultras加入者は予選敗北の翌日23:40までに登録すれば、敗北から2日後にすぐ再挑戦できる。

### 予選勝利 → Weekトーナメント敗退 → 再ローンチ

2026-09-07(月)にローンチして予選に勝利し、09-10(木)13時に参加費を決済してWeekトーナメントの参加資格を得て、2026-09-16(水)の準々決勝で敗退した場合。次回Yearトーナメント決済期限日は2027-05-24(月)23:35(決勝日2027-05-30、管理者設定)とする。

| 時点               | 選択可能なローンチ日                                     |
| ------------------ | -------------------------------------------------------- |
| 09-07〜09-16 23:40 | FR-RELCH-004により2027-05-24(月)より後の日のみ選択できる |
| 09-16 23:40以降    | FR-PRDCT-002により翌々日の09-18(金)以降を選択できる      |

Weekトーナメントに参加しなかった(決済期限の09-14 23:35までに決済しなかった)場合も、その時点(23:40より前)で制限を解除し、FR-PRDCT-002により翌日の09-15(火)以降を選択できる。

### Weekトーナメント優勝 → 再ローンチ

2026-09-18(金)にWeekトーナメントで優勝した場合、引き続きFR-RELCH-004により次回Yearトーナメント決済期限日(例: 決勝日が2027年5月の最終日曜日(2027-05-30、管理者が設定)なら、その6日前の2027-05-24(月)23:35)より後の日のみ選択できる。
Yearトーナメントへの参加資格を得てもこの制約自体は変わらない。2027-05-24 23:35が到来すればそれ以降の日は制約対象外になるため、その後Yearトーナメントで実際に敗退するか優勝するかにかかわらず、同時点から再ローンチ登録できる。決済期限までにYearトーナメントへの参加資格を得られなかった場合は、その時点で制限を解除する。

## 予約済みローンチの扱い

登録時点で適法だった再ローンチの予約は既得権として維持する。

| 事象                                                             | 予約の扱い                                   |
| ---------------------------------------------------------------- | -------------------------------------------- |
| 管理者がYearトーナメント決勝日を変更し、予約日が禁止期間に入った | 維持する                                     |
| 予約後にUltrasを解約した                                         | 維持する                                     |
| 予約日の前日23:45にペアリングされた                              | FR-PRDCT-012により変更・論理削除不可         |
| 管理者がプロダクトを非公開化した                                 | FR-ADMUG-008により未開始のローンチ予定を取消 |
| 投稿者が退会した                                                 | FR-PRDCT-013によりプロダクトと共に論理削除   |

## 制限の意図

| 制限                                                         | 意図                                                                                  |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| 敗北後7日(Ultrasは2日)                                       | 敗北直後の再投稿で予選枠を埋め尽くすことを防ぎつつ、改善して再挑戦するPDCAを促す      |
| 予選勝利後、次回Year決済期限まで再ローンチ制限(FR-RELCH-004) | 同一プロダクトが複数のローンチで並行してWeek/Yearトーナメント参加資格を持つことを防ぐ |
