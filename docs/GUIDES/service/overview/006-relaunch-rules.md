# 再ローンチ規則

一度ローンチしたプロダクトは、同じプロダクトとして何度でも再ローンチできる(FR-RELCH-001)。頻繁な再ローンチはハングリー精神の表れとして歓迎するが、勝者の独占・連投や、同一プロダクトによるトーナメント参加資格の重複を防ぐために間隔制限を設ける。
制限そのものはFR-RELCH-002〜004を正とし、本書は解釈・計算例・意図を補う。時刻は全て基準時刻(UTC-08:00)である。

## 間隔制限の解釈

| 直近ローンチの結果                                  | 対応要件          | 制限の種類                                               |
| --------------------------------------------------- | ----------------- | -------------------------------------------------------- |
| 予選敗北(0対0の両者敗北を含む)                      | FR-RELCH-002・003 | 選択できるローンチ日への制約                             |
| 予選勝利、Week/Yearの結果が未確定の間(不戦勝を含む) | FR-RELCH-004      | 次回ローンチの予約自体の禁止(Ultras加入でも早期解除なし) |

- 「ローンチ開始時間」はローンチ日の0:00である
- 全ての制限は「直近のローンチ」を基準にする。過去のローンチ結果は影響しない
- FR-RELCH-002・003の「選択できるローンチ日への制約」は該当する日をローンチ日の選択肢から除外し、制限を満たさない登録・編集リクエストはサーバー側でも拒否する。FR-PRDCT-002の翌日以降制約と併せて適用する
- FR-RELCH-004の「次回ローンチの予約自体の禁止」は、選択できる日を絞るのではなく予約という行為自体を拒否する。次回ローンチの予約は進行中のローンチとは別のローンチ記録として扱うため、この禁止はペアリング後〜マッチ終了まで進行中のローンチ自体を固定するFR-PRDCT-012とは独立しており、FR-PRDCT-012の状態(マッチ中か否か)が次回予約の可否を左右することはない
- FR-RELCH-004の「結果が確定していない間」がいつ終わるかはFR-RELCH-004本文(Week/Yearそれぞれの決済期限経過・敗退、Yearでの優勝)を参照。いずれかに該当した時点で禁止を即時解除し、以降はFR-PRDCT-002の制約にのみ従う

## Ultras加入状態の判定時点

再ローンチの間隔は、ローンチ日を登録・編集する時点のUltras加入状態で判定する。登録後に解約しても予約済みのローンチは維持する。

## 計算例

### 予選敗北 → 再ローンチ

2026-09-07(月)にローンチして予選に敗北した場合。

| 加入状態     | 選択可能な最も早いローンチ日 | 根拠                          |
| ------------ | ---------------------------- | ----------------------------- |
| 未加入       | 2026-09-14(月)               | 09-07 0:00 + 7日 = 09-14 0:00 |
| Ultras加入中 | 2026-09-09(水)               | 09-07 0:00 + 2日 = 09-09 0:00 |

Ultras加入者は予選敗北の翌日23:40までに登録すれば、敗北から2日後にすぐ再挑戦できる。

### 予選勝利 → Weekトーナメント敗退 → 再ローンチ

2026-09-07(月)にローンチして予選に勝利し、09-10(木)13時に参加費を決済してWeekトーナメントの参加資格を得て、2026-09-16(水)の準々決勝で敗退した場合。

| 時点               | 次回ローンチの予約                                                          |
| ------------------ | --------------------------------------------------------------------------- |
| 09-07〜09-16 23:40 | FR-RELCH-004により予約不可(結果が未確定のため)                              |
| 09-16 23:40以降    | 準々決勝敗退により確定。FR-PRDCT-002により翌々日の09-18(金)以降を予約できる |

Weekトーナメントに参加しなかった(決済期限の09-14 23:35までに決済しなかった)場合も、その時点(23:40より前)で結果が確定し禁止を解除するため、FR-PRDCT-002により翌日の09-15(火)以降を予約できる。

### Weekトーナメント優勝 → 再ローンチ

2026-09-18(金)にWeekトーナメントで優勝した場合、引き続きFR-RELCH-004により次回ローンチの予約自体ができない。Yearトーナメントへの参加資格を得てもこの禁止は変わらない。
決済期限(例: 決勝日が2027年5月の最終日曜日(2027-05-30、管理者が設定)なら、その6日前の2027-05-24(月)23:35)までにYearトーナメントへの参加資格を得られなかった場合は、その時点で禁止を解除する。参加資格を得た場合は、Yearトーナメントで敗退または優勝して結果が確定するまで禁止が続き、確定した時点でFR-PRDCT-002の制約にのみ従い次回ローンチを予約できる。

## 予約済みローンチの扱い

登録時点で適法だった再ローンチの予約は既得権として維持する。

| 事象                                | 予約の扱い                                   |
| ----------------------------------- | -------------------------------------------- |
| 予約後にUltrasを解約した            | 維持する                                     |
| 予約日の前日23:45にペアリングされた | FR-PRDCT-012により変更・論理削除不可         |
| 管理者がプロダクトを非公開化した    | FR-ADMUG-008により未開始のローンチ予定を取消 |
| 投稿者が停止された                  | FR-ADMUG-008により未開始のローンチ予定を取消 |
| 投稿者の停止が解除された            | 取消済みのため復元しない                     |
| 投稿者が退会した                    | FR-PRDCT-013によりプロダクトと共に論理削除   |

## 制限の意図

| 制限                                                          | 意図                                                                                  |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 敗北後7日(Ultrasは2日)                                        | 敗北直後の再投稿で予選枠を埋め尽くすことを防ぎつつ、改善して再挑戦するPDCAを促す      |
| 予選勝利後、Week/Yearの結果確定まで次回予約禁止(FR-RELCH-004) | 同一プロダクトが複数のローンチで並行してWeek/Yearトーナメント参加資格を持つことを防ぐ |
