# 法律及びコンプライアンス準拠方針

要件定義書の法的要件(LR-001〜009)・データ要件(DR-001〜017)を、本サービスのどの機能・運用で満たすかを整理する。法令の条文解釈や汎用的なプライバシー実務は本書の対象外とし、法務レビューの前提資料として用いる。

## 前提

| 項目         | 方針                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 準拠法・管轄 | 日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする                 |
| 利用年齢     | 18歳以上。登録時の利用規約同意に年齢要件の表明を含め、生年月日は収集しない(DR-001) |
| UI言語       | 日本語のみ。法務文書も日本語で提供する                                             |
| 通貨         | USD(I18N-003)                                                                      |
| 事業者情報   | 事業者名・所在地・連絡先は法的通知ページに記載する(値は管理者が管理画面で入力)     |

## 通知メールのオプトアウト(LR-005)

送信者情報の表示、配信停止手段、トークン、バウンス・苦情・拒否時の自動除外はFR-NOTIF-005・FR-NOTIF-007〜011・FR-NOTIF-015〜016を正とする。

| 項目   | 方針                                                                                         |
| ------ | -------------------------------------------------------------------------------------------- |
| 対象   | FR-NOTIF-001〜004の4種類(マッチ開始予告・勝敗結果・フォロー中ユーザーのマッチ開催・受賞結果) |
| 対象外 | それ以外の通知メール ... 取引・運営上必要な通知                                              |

## データ主体の権利への対応(LR-006)

| 権利                           | 対応機能                                                                                                                                                        | 応答時間の目安                   |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| アクセス・データポータビリティ | データエクスポート(FR-UDATA-001〜008、[構造](../features/001-user-data-export.md))。24時間に3回まで要求可(FR-RLMIT-005)                                         | 非同期生成、通常数分以内         |
| 訂正                           | プロフィール・プロダクト・コメントの自己編集                                                                                                                    | 即時                             |
| 消去                           | 退会(FR-USER-018)またはプロダクト・コメントの個別削除(FR-PRDCT-011・FR-COMNT-006)。定期課金は退会時に解約(FR-PPLAN-004)。詳細は後述のデータ保持期間の一覧を参照 | 14日以内                         |
| 処理の制限・異議               | 通知種別ごとのオプトアウト。その他は問い合わせフォームで受け付け管理者が対応                                                                                    | 問い合わせの対応ステータスで管理 |
| 自動処理に関する権利           | ペアリング・勝敗判定・画像自動判定は自動処理だが、法的効果や重大な影響を伴わない。画像の自動判定は管理者の手動モデレーション(FR-ADMUG-013)で再審査される        | —                                |

退会後も保持するデータ: 監査ログ(3年、仮名化IDのみ)、決済履歴(7年、仮名化IDのみ)、匿名化したコメント、匿名化したマッチ記録。仮名化ID(FR-USER-004)は本プロジェクトのデータベース内でユーザー主キーと外部キー関係を持たず、物理削除後はデータベース内の情報のみでは個人を識別できない。

ただしStripe側では、税務上の記録保存義務によりCharge・PaymentIntent・Invoiceが氏名・メールアドレス等をCustomerとは独立したスナップショットとして保持期間中保持し続ける。退会ユーザーの物理削除時にStripe Customerオブジェクト自体を削除しても、これらのスナップショットは消えない。一括削除機能(Redaction Jobs)は返金・異議申立ができなくなるため採用しない。

## データの保存場所(DR-007)

プライバシーポリシーに保存先を明示する。具体的なリージョン・ロケーションはインフラ構成(`docs/GUIDES/tech/infra`)を正とし、変更時はプライバシーポリシーの改訂履歴に記録する。

| データ                                         | 保存先                     |
| ---------------------------------------------- | -------------------------- |
| アカウント・投稿・決済履歴等                   | Cloudflare D1              |
| 画像・添付ファイル・エクスポート               | Cloudflare R2              |
| アプリケーションログ                           | Cloudflare Workers Logs    |
| レート制限カウント(一時的)                     | Cloudflare Durable Objects |
| 通知・エクスポート等のジョブメッセージ(一時的) | Cloudflare Queues          |

外部サービスへ一時送信する情報と保持しない旨は[委託先の一覧](003-privacy-policy-outline.md#委託先の一覧)を正とする。

## Cookieとトラッキング

- 認証Cookie(NFR-SECUR-001)を使用する。サービス提供に必須のため同意バナーを表示しない
- 決済画面で読み込むStripe.jsは不正検知(Stripe Radar)のため、本サービスのドメインへファーストパーティCookieとして設置する。[カードテスティング](https://docs.stripe.com/disputes/prevention/fraud-types#card-testing)等の不正決済防止に必須の措置で、同意バナーの対象外である
  - `__stripe_mid`(デバイス識別用、有効期間1年)、`m.stripe.com`へ定期送信する
  - `__stripe_sid`(決済セッション識別用、有効期間30分)
- アクセス解析はCloudflare Web Analytics(SW-006、Cookie・個人識別子を使用しない)を用いる
- 広告トラッキング、サードパーティCookie、リターゲティングは行わない
- Stripe Payment Elementのカード入力欄はiframe内でStripe側のCookieを扱う

(注1) 画像ファイルは物理削除と同時にエッジキャッシュを即時無効化する(FR-FILEU-019、[キャッシュとパージ](../features/002-image-variants.md#キャッシュとパージ))。ただしブラウザキャッシュはサーバー側から制御できないため、`Cache-Control: max-age=1209600`により最長14日、物理削除された画像がURLを知る第三者の端末に残存し得る。

(注2) 返信ツリー構造の親コメントが消えないよう、コメント行自体は無期限に保持する。匿名化の方式はFR-COMNT-009、削除時の表示はFR-COMNT-007を正とし、匿名化後の行にユーザーを識別できる情報は残らない。

(注3) 対戦相手側の勝敗・Upvote記録と、Yearトーナメントのシード計算(FR-TOURY-005、Week優勝から参加費決済期限まで最長63週)に必要な予選Upvote数を守るため、マッチ記録の行自体は無期限に保持する。紐付け解除の方式はFR-PRDCT-015を正とし、解除後の行にユーザーを識別できる情報は残らない。

(注4) 「未対応」「対応中」のまま更新が止まっている項目は削除対象とせず、管理者が手動でステータスを変更する。通報については、未ログインユーザーが「権利侵害」カテゴリを選択した場合に入力される連絡先メールアドレス(FR-REPOT-003)もこの削除方法に含まれる。

(注5) 保持の開始条件・置き換え・リダイレクトはFR-USER-018・FR-UPROF-010〜012・FR-PRDCT-018〜020・FR-ADMAG-021〜023・FR-HELP-011を、予約語一覧は[URL構造](../design/002-page-layouts.md#旧ハンドルの保持とリダイレクト)を参照。保持中の旧ハンドル文字列は例外的に、ユーザー・プロダクトは退会時(FR-USER-018)、ヘルプ記事は削除時(FR-ADMAG-022)に消去する。

## モデレーションと透明性

- 停止・非公開化は理由付きで行い投稿者へ通知する(FR-ADMUG-019)。全ての管理者操作は監査ログに記録し、対象ユーザーは仮名化IDで記録する(FR-ADMAG-001〜003)
- 通報は同一コンテンツで集約し(FR-ADMUG-018)、繰り返し通報による過剰対応を防ぐ

## 法務文書の改訂

利用規約・プライバシーポリシー・法的通知の編集と改訂履歴の表示はFR-ADMAG-006〜008を正とする。重要な変更はユーザーへの周知期間を設ける運用とし、その要否は法務レビューで判断する。
