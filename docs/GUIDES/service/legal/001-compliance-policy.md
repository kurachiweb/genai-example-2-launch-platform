# 法律及びコンプライアンス準拠方針

要件定義書の法的要件(LR-001〜013)・データ要件(DR-001〜026)を、本サービスのどの機能・運用で満たすかを整理する。法令の条文解釈や汎用的なプライバシー実務は本書の対象外とし、法務レビューの前提資料として用いる。

## 前提

| 項目         | 方針                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------ |
| 準拠法・管轄 | 日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする                         |
| 利用年齢     | 18歳以上。登録時の利用規約同意に年齢要件の表明を含め、生年月日は収集しない(DR-001)         |
| UI言語       | 日本語のみ。法務文書も日本語で提供する                                                     |
| 通貨         | USD(I18N-003)                                                                              |
| 事業者情報   | 事業者名・所在地・連絡先メールアドレスは法的通知ページと通知メール(FR-ADMCF-024)に記載する |

## 通知メールのオプトアウト(LR-005)

受信設定の初期値、送信者情報の設定と表示、配信停止手段、トークン、バウンス・苦情・拒否時の自動除外はFR-ADMCF-024・FR-NOTIF-008・FR-NOTIF-010・012・016〜018・FR-NOTIF-022〜023を正とする。

| 項目   | 方針                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------ |
| 対象   | FR-NOTIF-001・004・006・007の4種類(マッチ開始予告・勝敗結果・フォロー中ユーザーのマッチ開催・受賞結果) |
| 対象外 | それ以外の通知メール ... 取引・運営上必要な通知                                                        |

退会後も保持するデータ: 監査ログ(3年、仮名化IDのみ)、決済履歴(7年、仮名化IDのみ)、匿名化したコメント、匿名化したマッチ記録。仮名化ID(FR-USER-004)は本プロジェクトのデータベース内でユーザー主キーと外部キー関係を持たず、物理削除後はデータベース内の情報のみでは個人を識別できない。

ただしStripe側では、税務上の記録保存義務によりCharge・PaymentIntent・Invoiceが氏名・メールアドレス等をCustomerとは独立したスナップショットとして保持期間中保持し続ける。退会ユーザーの物理削除時にStripe Customerオブジェクト自体を削除しても、これらのスナップショットは消えない。一括削除機能(Redaction Jobs)は返金・異議申立ができなくなるため採用しない。

## データの保存場所(DR-012)

プライバシーポリシーに保存先を明示する。具体的なリージョン・ロケーションはインフラ構成(`docs/GUIDES/tech/infra`)を正とし、変更時はプライバシーポリシーの改訂履歴に記録する。

| データ                                         | 保存先                     |
| ---------------------------------------------- | -------------------------- |
| アカウント・投稿・決済履歴等                   | Cloudflare D1              |
| 画像・添付ファイル・エクスポート               | Cloudflare R2              |
| アプリケーションログ                           | Cloudflare Workers Logs    |
| レート制限カウント(一時的)                     | Cloudflare Durable Objects |
| 通知・エクスポート等のジョブメッセージ(一時的) | Cloudflare Queues          |

外部サービスへ一時送信する情報と保持しない旨は[委託先の一覧](003-privacy-policy-outline.md#委託先の一覧)を正とする。

## Cookieとトラッキング

- 認証Cookie(NFR-SECUR-001)を使用する。サービス提供に必須のため同意バナーを表示しない
- 決済画面で読み込むStripe.jsは不正検知(Stripe Radar)のため、本サービスのドメインへファーストパーティCookieとして設置する。[カードテスティング](https://docs.stripe.com/disputes/prevention/fraud-types#card-testing)等の不正決済防止に必須の措置で、同意バナーの対象外である
  - `__stripe_mid`(デバイス識別用、有効期間1年)、`m.stripe.com`へ定期送信する
  - `__stripe_sid`(決済セッション識別用、有効期間30分)
- Cloudflareのbot対策・チャレンジ(Turnstile・WAF等)により、本サービスのドメインへ次のCookieが設置され得る。不正アクセス防止に必須の措置で、同意バナーの対象外である([Cloudflareの一覧](https://developers.cloudflare.com/fundamentals/reference/policies-compliances/cloudflare-cookies/))
  - `__cf_bm`(bot判定用、無操作30分で失効)
  - `cf_clearance`(チャレンジ通過の記録用、有効期間はChallenge Passage設定に従う)
- アクセス解析はCloudflare Web Analytics(SW-006、Cookie・個人識別子を使用しない)を用いる
- 広告トラッキングとリターゲティングは行わず、広告・解析目的のサードパーティCookieも使わない
- Stripe Payment Elementでカード入力欄を表示するiframeは、Stripeが設定するサードパーティCookieを扱う。決済に必須のため、同意バナーの対象外である

(注2) 返信ツリー構造の親コメントが消えないよう、コメント行自体は無期限に保持する。匿名化の方式はFR-COMNT-009、削除時の表示はFR-COMNT-007を正とし、匿名化後の行にユーザーを識別できる情報は残らない。

(注6) 上記のD1に保存されたデータは、削除・匿名化後もD1 Time Travelによりバックアップに最長30日残存する。これは退会・削除後14日以内の物理削除(DR-002)の例外とする。

(注7) 抑止記録は、通知メールを送らない宛先の記録である。照合用のメールアドレス(小文字)・最後の契機の種類と日時・期限だけを持ち、配信不能イベントに含まれる件名や配送サーバーの応答を保存しない。同じメールアドレスに新しい契機が届くと最後の契機と期限を更新し、期限なしの抑止は期限付きに戻らない。退会の処理での物理削除は、退会から14日以内(DR-002)に行う。利用者に登録済みかを確かめられない日は、利用者に紐づかない記録を削除しない。利用者に登録済みかの確認は、毎日照合用のメールアドレスの昇順で先頭から1,800件までに限る。前日の続きから確かめないため、最後の契機から1年を過ぎても利用者に登録済みの記録が先頭の1,800件を占めると、それより後ろの利用者に紐づかない記録は1年を過ぎても削除されない。

(注8) 同じメールを重複して送らないための記録で、送信要求の識別子・メール種別・送信日時だけを持ち、宛先・件名・本文を持たない。14日は、重複して届き得る送信要求をQueuesが保持する期間の上限である。

## モデレーションと透明性

- 停止・非公開化は理由付きで行い投稿者へ通知する(FR-ADMUG-030)。監査対象の管理者操作は監査ログに記録し、対象ユーザーは仮名化IDで記録する(FR-ADMAG-001〜003)
- 通報は同一コンテンツで集約し(FR-ADMUG-027)、繰り返し通報による過剰対応を防ぐ

## 法務文書の改訂

利用規約・プライバシーポリシー・法的通知の編集と改訂履歴の表示はFR-ADMAG-007・008・010を正とする。重要な変更はユーザーへの周知期間を設ける運用とし、その要否は法務レビューで判断する。
