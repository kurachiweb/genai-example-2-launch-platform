# 法律及びコンプライアンス準拠方針

要件定義書の法的要件(LR-001〜008)・データ要件(DR-001〜013)を、本サービスのどの機能・運用で満たすかを整理する。法令の条文解釈や汎用的なプライバシー実務は本書の対象外とし、法務レビューの前提資料として用いる。

## 前提

| 項目             | 方針                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 準拠法・管轄     | 日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする                       |
| 利用年齢         | 18歳以上。登録時の利用規約同意に年齢要件の表明を含め、生年月日は収集しない(DR-001)       |
| UI言語           | 日本語のみ。法務文書も日本語で提供する                                                   |
| 通貨             | USD                                                                                      |
| 事業者情報       | 事業者名・所在地・連絡先は法的通知ページに記載する(値は管理者が管理画面で入力)           |

## 法的要件と対応機能の対応表

| 要件   | 法令・規制                                       | 対応する機能・運用                                                                                         |
| ------ | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| LR-001 | —                                                | 利用者側の全ページのフッターに利用規約・プライバシーポリシー・法的通知へのリンク                          |
| LR-002 | 特定商取引法(通信販売)                           | 法的通知ページに事業者情報・価格・支払方法・返金ポリシーを記載([法的通知の大枠](004-legal-notice-outline.md)) |
| LR-003 | 景品表示法(優良誤認)                             | Turnstile検証、1ユーザー1マッチ1Upvote、自身のプロダクトへのUpvote・評価禁止、使い捨てメール判定、停止ユーザーのUpvote除外、管理者による評価無効化 |
| LR-004 | 著作権法、情報流通プラットフォーム対処法         | 利用規約でのUGC著作権帰属の明確化、通報カテゴリ「著作権侵害」、対応期間の可視化([侵害コンテンツ削除請求フロー](005-copyright-takedown-flow.md)) |
| LR-005 | 特定電子メール法、CAN-SPAM法                     | 通知メールへの送信者情報表示、通知種別ごとのオプトアウト、RFC 8058のワンクリック配信停止、バウンス・苦情の自動除外 |
| LR-006 | 個人情報保護法、GDPR、CCPA/CPRA、LGPD            | [プライバシーポリシーの大枠](003-privacy-policy-outline.md)と後述のデータ主体の権利対応                    |
| LR-007 | 消費者契約法、各国消費者保護法(自動更新・解約)   | Ultras加入前の価格・自動更新・解約条件の表示、いつでも解約可、期間末まで特典継続                           |
| LR-008 | 景品表示法(ステルスマーケティング規制)           | スポンサー広告への「スポンサー」ラベル、`rel="sponsored"`                                                  |

## 不正投票・実績操作の防止(LR-003)

| 対策                                   | 内容                                                                     |
| -------------------------------------- | ------------------------------------------------------------------------ |
| bot対策                                | 登録・ログイン・Upvote・コメント・通報等の操作でTurnstile検証            |
| 1ユーザー1票                           | 1ユーザー1マッチにつき1Upvote。取り消しは可能だが再投票も1票のまま       |
| 利害関係者の除外                       | 自身のプロダクトとその対戦相手へのUpvote・自身のプロダクトへの評価を拒否 |
| 複数アカウント対策                     | メールアドレス確認必須、使い捨てメールアドレスの判定と管理者への表示、レート制限 |
| 事後対応                               | 管理者によるユーザー停止(停止時点でマッチ中のUpvoteを即時除外)、評価の無効化、監査ログ |
| 表示上の誠実さ                         | Upvote数はマッチ毎に集計し過去の数値を再利用しない。平均評価は無効化分を除外 |

## 通知メールのオプトアウト(LR-005)

| 項目               | 方針                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| 対象               | マッチ開始予告・勝敗結果・フォロー中ユーザーのマッチ開催・受賞結果の4種類                      |
| 対象外             | メールアドレス確認、パスワードリセット、データエクスポート完了、問い合わせ返信、停止・非公開化通知(取引・運営上必要な通知) |
| 送信者情報         | 事業者名・連絡先・物理的郵送先住所を本文末尾に表示                                             |
| 配信停止手段       | 通知設定ページ(ログイン)、本文内リンク(ログイン不要、確認操作のみ)、RFC 8058ワンクリック(メールクライアント) |
| 配信停止トークン   | ユーザー×通知種別ごとに発行、退会まで有効                                                      |
| 自動除外           | バウンス・苦情・拒否を検知したアドレスは送信対象から除外し、通知設定ページにその旨を表示       |

## データ主体の権利への対応(LR-006)

| 権利                     | 対応機能                                                                          | 応答時間の目安                     |
| ------------------------ | --------------------------------------------------------------------------------- | ---------------------------------- |
| アクセス・データポータビリティ | データエクスポート(ZIP、JSON+原本ファイル)。24時間に1回要求可                  | 非同期生成、通常数分以内           |
| 訂正                     | プロフィール・プロダクト・コメントの自己編集                                      | 即時                               |
| 消去                     | 退会(論理削除)→14日以内に物理削除(DR-002)。定期課金は退会時に解約                 | 14日以内                           |
| 処理の制限・異議         | 通知種別ごとのオプトアウト。その他は問い合わせフォームで受け付け管理者が対応      | 問い合わせの対応ステータスで管理   |
| 自動処理に関する権利     | ペアリング・勝敗判定・画像自動判定は自動処理だが、法的効果や重大な影響を伴わない。画像の自動判定は管理者の手動モデレーションで再審査される | — |

退会後も保持するデータ: 監査ログ(3年、仮名化IDのみ)、決済履歴(7年、仮名化IDのみ)。仮名化IDはユーザー主キーと外部キー関係を持たず、物理削除後は個人を識別できない。

## データの保存場所(DR-007)

プライバシーポリシーに以下の区分で保存先を明示する。具体的なリージョン・ロケーションはインフラ構成(`docs/GUIDES/tech/infra`)を正とし、変更時はプライバシーポリシーの改訂履歴に記録する。

| データ                         | 保存先                                      |
| ------------------------------ | ------------------------------------------- |
| アカウント・投稿・決済履歴等   | Cloudflare D1                               |
| 画像・添付ファイル・エクスポート | Cloudflare R2                              |
| レート制限カウント             | Cloudflare Durable Objects(一時的)          |
| 決済情報(カード番号等)         | Stripe(自社サーバーには保持しない、DR-005)  |
| 画像の自動判定                 | Amazon Rekognition(判定時に一時送信、保存しない) |
| キーワード抽出                 | Google Cloud Natural Language AI(抽出時に一時送信、保存しない) |
| エラートラッキング             | Sentry(IPアドレスを除去して送信)            |
| 使い捨てメール判定             | DISIFY API(ローカル部をダミーに置き換えて送信) |
| 漏洩パスワード照合             | Have I Been Pwned(ハッシュ先頭5文字のみ送信) |

## Cookieとトラッキング

- 使用するCookieは認証Cookie(`__Host-`プレフィックス)のみで、サービス提供に必須のため同意バナーを表示しない
- アクセス解析はCloudflare Web Analytics(Cookie・個人識別子を使用しない)を用いる
- 広告トラッキング、サードパーティCookie、リターゲティングは行わない
- Stripe Payment Elementはiframe内でStripeのCookieを使用する。プライバシーポリシーにStripeへの委託として記載する

## データ保持期間の一覧

| データ                             | 保持期間                                        | 削除方法             |
| ---------------------------------- | ----------------------------------------------- | -------------------- |
| 退会ユーザーの個人データ・ファイル | 退会から14日                                    | 日次バッチで物理削除 |
| データエクスポートZIP              | 生成完了から7日                                 | 日次バッチで物理削除 |
| 監査ログ                           | 3年                                             | 日次バッチで物理削除 |
| 決済履歴                           | 7年                                             | 日次バッチで物理削除 |
| アプリケーションログ               | 7日(Cloudflare Workers Logsの上限)、個人情報はマスキング | 自動              |
| ログインセッション                 | 利用者: アイドル14日・絶対90日、管理者: アイドル1時間・絶対12時間 | 失効時に物理削除 |
| 認証系トークン                     | 30分〜24時間、1回使用で失効                     | 失効時に無効化       |
| 隔離バケットの画像                 | 管理者の判断まで                                | 拒否時に削除         |

## モデレーションと透明性

- ユーザー停止・プロダクト/コメント非公開化・評価無効化は理由付きで行い、投稿者へ理由を通知する(FR-ADMUG-018)
- 全ての管理者操作は監査ログに記録し、対象ユーザーは仮名化IDで記録する。理由欄には個人情報を含めない
- 通報は同一コンテンツで集約し、繰り返し通報による過剰対応を防ぐ

## 法務文書の改訂

利用規約・プライバシーポリシー・法的通知は最上位管理者が管理画面で編集し、変更概要と保存日時を改訂履歴として各ページ末尾に表示する。重要な変更はユーザーへの周知期間を設ける運用とし、その要否は法務レビューで判断する。
