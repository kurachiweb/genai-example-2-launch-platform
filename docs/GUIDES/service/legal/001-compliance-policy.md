# 法律及びコンプライアンス準拠方針

要件定義書の法的要件(LR-001〜008)・データ要件(DR-001〜015)を、本サービスのどの機能・運用で満たすかを整理する。法令の条文解釈や汎用的なプライバシー実務は本書の対象外とし、法務レビューの前提資料として用いる。

## 前提

| 項目         | 方針                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 準拠法・管轄 | 日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする                 |
| 利用年齢     | 18歳以上。登録時の利用規約同意に年齢要件の表明を含め、生年月日は収集しない(DR-001) |
| UI言語       | 日本語のみ。法務文書も日本語で提供する                                             |
| 通貨         | USD(I18N-003)                                                                      |
| 事業者情報   | 事業者名・所在地・連絡先は法的通知ページに記載する(値は管理者が管理画面で入力)     |

## 通知メールのオプトアウト(LR-005)

送信者情報の表示、配信停止手段、トークン、バウンス・苦情・拒否時の自動除外はFR-NOTIF-005・FR-NOTIF-007〜011・FR-NOTIF-015〜016を正とする。

| 項目   | 方針                                                                                                                                                                                |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 対象   | FR-NOTIF-001〜004の4種類(マッチ開始予告・勝敗結果・フォロー中ユーザーのマッチ開催・受賞結果)                                                                                        |
| 対象外 | メールアドレス確認、パスワードリセット、データエクスポート完了、問い合わせ返信、停止・非公開化通知、スポンサー広告関連通知(掲載開始・掲載終了・強制終了) ... 取引・運営上必要な通知 |

## データ主体の権利への対応(LR-006)

| 権利                           | 対応機能                                                                                                                                                          | 応答時間の目安                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| アクセス・データポータビリティ | データエクスポート(FR-UDATA-001〜008、[構造](../features/001-user-data-export.md))。24時間に1回要求可(FR-RLMIT-005)                                               | 非同期生成、通常数分以内         |
| 訂正                           | プロフィール・プロダクト・コメントの自己編集                                                                                                                      | 即時                             |
| 消去                           | 退会(FR-USER-017)→14日以内に物理削除(FR-USER-018、DR-002)。コメント及びマッチ記録は後述の保持期間一覧の注2・注3に従い匿名化。定期課金は退会時に解約(FR-PPLAN-004) | 14日以内                         |
| 処理の制限・異議               | 通知種別ごとのオプトアウト。その他は問い合わせフォームで受け付け管理者が対応                                                                                      | 問い合わせの対応ステータスで管理 |
| 自動処理に関する権利           | ペアリング・勝敗判定・画像自動判定は自動処理だが、法的効果や重大な影響を伴わない。画像の自動判定は管理者の手動モデレーション(FR-ADMUG-013)で再審査される          | —                                |

退会後も保持するデータ: 監査ログ(3年、仮名化IDのみ)、決済履歴(7年、仮名化IDのみ)、匿名化したコメント、匿名化したマッチ記録。仮名化ID(FR-USER-004)は本プロジェクトのデータベース内でユーザー主キーと外部キー関係を持たず、物理削除後はデータベース内の情報のみでは個人を識別できない。

ただしStripe側では、税務上の記録保存義務によりCharge・PaymentIntent・Invoiceが氏名・メールアドレス等をCustomerとは独立したスナップショットとして保持期間中保持し続ける。退会ユーザーの物理削除時にStripe Customerオブジェクト自体を削除しても、これらのスナップショットは消えない。一括削除機能(Redaction Jobs)は返金・異議申立ができなくなるため採用しない。

## データの保存場所(DR-007)

プライバシーポリシーに保存先を明示する。具体的なリージョン・ロケーションはインフラ構成(`docs/GUIDES/tech/infra`)を正とし、変更時はプライバシーポリシーの改訂履歴に記録する。

| データ                           | 保存先                             |
| -------------------------------- | ---------------------------------- |
| アカウント・投稿・決済履歴等     | Cloudflare D1                      |
| 画像・添付ファイル・エクスポート | Cloudflare R2                      |
| レート制限カウント               | Cloudflare Durable Objects(一時的) |

外部サービスへ一時送信する情報と保持しない旨は[委託先の一覧](003-privacy-policy-outline.md#委託先の一覧)を正とする。

## Cookieとトラッキング

- 認証Cookie(NFR-SECUR-001)を使用する。サービス提供に必須のため同意バナーを表示しない
- Stripe.js自体が不正検知(Stripe Radar)のため、本サービスのドメインへファーストパーティCookieとして設置する。[カードテスティング](https://docs.stripe.com/disputes/prevention/fraud-types#card-testing)等の不正決済防止に必須の措置で、同意バナーの対象外である
  - `__stripe_mid`(デバイス識別用、有効期間1年)、`m.stripe.com`へ定期送信する
  - `__stripe_sid`(決済セッション識別用、有効期間30分)
- アクセス解析はCloudflare Web Analytics(SW-006、Cookie・個人識別子を使用しない)を用いる
- 広告トラッキング、サードパーティCookie、リターゲティングは行わない
- Stripe Payment Elementのカード入力欄はiframe内でStripe側のCookieを扱う

## データ保持期間の一覧

| データ                             | 保持期間                               | 削除方法                                                                                             | 対応要件            |
| ---------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------- |
| 退会ユーザーの個人データ・ファイル | 退会から14日(注1)                      | 日次バッチで物理削除                                                                                 | FR-USER-018、DR-002 |
| 退会ユーザーのコメント             | 無期限(注2)                            | 退会から14日で本文空文字化・投稿者情報の紐付け解除(行自体は物理削除しない)                           | FR-COMNT-009        |
| 退会ユーザーが関与したマッチ記録   | 無期限(注3)                            | 退会から14日でプロダクト識別情報の紐付け解除(行自体・対戦相手側の記録は物理削除しない)               | FR-PRDCT-015        |
| データエクスポートZIP              | 生成完了から7日                        | 日次バッチで物理削除                                                                                 | DR-004              |
| 監査ログ                           | 3年                                    | 日次バッチで物理削除                                                                                 | DR-012              |
| 決済履歴                           | 7年                                    | 日次バッチで物理削除                                                                                 | DR-013              |
| アプリケーションログ               | 7日、個人情報はマスキング              | 自動                                                                                                 | DR-008              |
| ログインセッション                 | NFR-SECUR-028のアイドル・絶対有効期限  | ログアウト等(NFR-SECUR-029〜030)は即時物理削除、それ以外は絶対有効期限の超過後に日次バッチで物理削除 | DR-014              |
| 認証系トークン                     | NFR-SECUR-033の有効期限、1回使用で失効 | 使用時・再発行時は無効化(NFR-SECUR-035)、未使用のまま有効期限を超過した場合は日次バッチで物理削除    | DR-015              |
| 隔離バケットの画像                 | 管理者の判断まで                       | 拒否時に削除                                                                                         | FR-ADMUG-013        |

日次バッチの実行時刻は[日次タイムライン](../overview/007-daily-timeline.md#日次タイムライン)を参照。

(注1) 画像ファイルは物理削除と同時にエッジキャッシュを即時無効化する(FR-FILEU-019、[キャッシュとパージ](../features/002-image-variants.md#キャッシュとパージ))。ただしブラウザキャッシュはサーバー側から制御できないため、`Cache-Control: max-age=1209600`により最長14日、退会ユーザーの画像がURLを知る第三者の端末に残存し得る。

(注2) 返信ツリー構造(最大3階層)を維持し、他ユーザーが付けた返信の親コメントが消えることを防ぐため、コメント行自体は無期限に保持し、FR-COMNT-007の「削除された旨」表示を維持する。ただし匿名化(本文空文字化・投稿者情報の紐付け解除)は退会から14日以内に行うため、匿名化後の行にユーザーを識別できる情報は残らない。

(注3) 対戦相手プロダクト側の勝敗・Upvote記録を維持し、トーナメントのラウンド進行表示に歯抜けが生じることを防ぐため、マッチ記録の行自体は無期限に保持する。またYearトーナメントのシード計算(FR-TOURY-005)はProduct of the Week受賞に至った予選のUpvote数を決勝日の直前まで参照するため、退会から14日以内の物理削除では対応できない。匿名化(退会ユーザーが投稿したプロダクト側の識別情報の紐付け解除)は退会から14日以内に行うため、匿名化後の行にユーザーを識別できる情報は残らない。

## モデレーションと透明性

- 停止・非公開化・無効化は理由付きで行い投稿者へ通知する(FR-ADMUG-018)。全ての管理者操作は監査ログに記録し、対象ユーザーは仮名化IDで記録する(FR-ADMAG-001〜003)
- 通報は同一コンテンツで集約し(FR-ADMUG-017)、繰り返し通報による過剰対応を防ぐ

## 法務文書の改訂

利用規約・プライバシーポリシー・法的通知の編集と改訂履歴の表示はFR-ADMAG-006〜008を正とする。重要な変更はユーザーへの周知期間を設ける運用とし、その要否は法務レビューで判断する。
