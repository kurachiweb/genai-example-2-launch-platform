# 法的通知の大枠

管理者が管理画面で編集する法的通知ページ(FR-ADMAG-007)の構成。特定商取引法に基づく表記(LR-008)を中心に、事業者としての法定表示をまとめる。事業者情報の値は本書に書かず、管理画面で入力する。決済直前の最終確認画面(12条の6)の表示事項は本書の対象外とし、[ページ構成](../design/002-page-layouts.md#決済前の最終確認画面)を正とする。

## 章立て

| 章  | タイトル               | 記載事項                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 事業者情報             | 事業者名(氏名または名称)、所在地(物理的郵送先住所)、電話番号(請求があれば遅滞なく開示する旨でも可)、メールアドレスまたは問い合わせフォーム、代表者または運営責任者                                                                                                                                                                                                                                       |
| 2   | 販売価格               | Ultras月額、Weekトーナメント参加費、Yearトーナメント参加費、スポンサー広告の1日単価(Legend/Gold/Silver)。価格は税込表示である旨(LR-009)、各申し込み画面に表示する旨                                                                                                                                                                                                                                      |
| 3   | 商品代金以外の必要料金 | 通信費は利用者負担、為替手数料はカード会社の定めによる旨                                                                                                                                                                                                                                                                                                                                                 |
| 4   | 申込みの期間           | 申込みの期間に定めがあるもの(トーナメント参加費の決済期限)のみ記載する。期限は[トーナメント参加費の導線](../design/002-page-layouts.md#トーナメント参加費の導線)を正とする                                                                                                                                                                                                                               |
| 5   | 支払方法・時期         | 利用できる決済手段(FR-PYMNT-001)として「クレジットカード・デビットカード、Apple Pay、Google Pay、Link(Linkでは登録したカードのほか、米国の銀行口座による即時銀行決済などが使える場合がある)」を列挙する。申し込み時に決済。Ultrasは毎月の更新日に自動決済                                                                                                                                                |
| 6   | 役務の提供時期         | 決済完了後直ちに提供(Ultras特典・トーナメント参加資格)、スポンサー広告は選択した掲載期間                                                                                                                                                                                                                                                                                                                 |
| 7   | 返金・キャンセル       | 後述の「返金ポリシー」                                                                                                                                                                                                                                                                                                                                                                                   |
| 8   | 定期課金(Ultras)の条件 | 月額、自動更新、解約はいつでも可能で当該課金期間末まで特典継続、日割り返金なし、支払い失敗時は自動で再試行し(再試行中は特典継続)、再試行でも決済できなければ特典終了。解約の方法として、プラン管理画面(`/settings/plan`)から開くStripe Customer Portalで解約・解約の取り消し・支払い方法の更新を行う旨(FR-PPLAN-010)。解約を受け付けた際は、受け付けた日時と特典の終了日時を記載した確認のメールを送る旨 |
| 9   | 動作環境               | 要件定義書2.4節のクライアント要件                                                                                                                                                                                                                                                                                                                                                                        |
| 10  | 通知メールの送信者情報 | 特定電子メール法・CAN-SPAM法に基づく送信者名・住所・連絡先メールアドレス(FR-ADMCF-024で設定する通知メール末尾の送信者情報と同じ内容)                                                                                                                                                                                                                                                                     |
| 11  | 準拠法・管轄           | [準拠方針の前提](001-compliance-policy.md#前提)に従う                                                                                                                                                                                                                                                                                                                                                    |

## 返金ポリシー

| 状況                                                                                 | 対応                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 原則                                                                                 | デジタル役務の性質上、決済完了後の返金は行わない                                                                                                                                                                                                                                                                             |
| EU・英国の消費者の14日間の撤回権                                                     | 最終確認画面で即時提供への同意と撤回権を失う旨の了知を得るため、返金しない                                                                                                                                                                                                                                                   |
| 二重決済                                                                             | 重複分を返金する                                                                                                                                                                                                                                                                                                             |
| システム障害により役務を提供できなかった                                             | 返金する                                                                                                                                                                                                                                                                                                                     |
| トーナメントの不戦勝・不戦敗・両者敗北                                               | 参加資格は付与済みのため返金しない                                                                                                                                                                                                                                                                                           |
| ユーザー停止に伴う定期課金(Ultras)の解約                                             | 当該課金期間の末日で終了するよう定期課金を解約し、返金しない。停止を解除しても定期課金は自動で再開しない(FR-PPLAN-012)                                                                                                                                                                                                       |
| 退会に伴う定期課金(Ultras)の解約                                                     | 退会の時点で定期課金を即時に解約し、返金しない。特典は日の終わりを待たずにその時点で終わる(FR-PPLAN-004・005)                                                                                                                                                                                                                |
| 組み合わせ決定の時点のユーザー停止やプロダクト非公開化に伴うトーナメント参加資格停止 | 決済した参加費を自動で全額返金する(FR-PYMNT-011。ユーザーの規約違反でも停止は事業者側の都合であるため)                                                                                                                                                                                                                       |
| Yearトーナメントの参加数の上限(64)を超えたことに伴うトーナメント参加資格停止         | 決済した参加費を自動で全額返金する(FR-PYMNT-011)。上限を超えた場合はProduct of the Week優勝の日時が新しい順に64個を対象とし、残りの参加資格を停止する(FR-TOURY-011)                                                                                                                                                          |
| 組み合わせ決定前のプロダクト削除に伴うトーナメント参加資格喪失                       | 決済した参加費を自動で全額返金する(FR-PYMNT-010)                                                                                                                                                                                                                                                                             |
| 組み合わせ決定前の退会に伴うトーナメント参加資格喪失                                 | 決済した参加費を自動で全額返金する(FR-PYMNT-010)                                                                                                                                                                                                                                                                             |
| 組み合わせ決定までに決済を参加資格へ反映できなかった                                 | 決済した参加費を自動で全額返金する(FR-PYMNT-014)                                                                                                                                                                                                                                                                             |
| 決済の確定の時点で購入した権利を付与できなかった                                     | 権利を付与せず、決済した金額を自動で全額返金する(FR-PYMNT-017)。決済期限の後に反映されたトーナメント参加費で、同じプロダクトのより新しいローンチが予約済みだった場合(FR-TOURW-006・FR-TOURY-008)や、スポンサー広告の掲載期間が、同じプロダクト・同じティアの決済済みで終了していない広告と重なっていた場合(FR-SPONS-006)など |
| 管理者によるスポンサー広告の強制終了                                                 | 未掲載日数分を自動で返金する                                                                                                                                                                                                                                                                                                 |
| ユーザー停止やプロダクト非公開化に伴うスポンサー広告の表示停止                       | 表示を停止した日数分を自動で返金する                                                                                                                                                                                                                                                                                         |
| 投稿者によるプロダクト削除・退会に伴うスポンサー広告の掲載終了                       | 返金しない                                                                                                                                                                                                                                                                                                                   |
| 定期課金の解約                                                                       | 当該課金期間末まで特典を継続し(FR-PPLAN-003)、日割り返金はしない                                                                                                                                                                                                                                                             |
| 決済したトーナメント参加費の後の定期課金(Ultras)への加入                             | 加入より前に決済した参加費は、加入を理由に返金しない(FR-PPLAN-009)。料金ページと最終確認画面に支払い済みの参加費は返金されない旨を表示する                                                                                                                                                                                   |
| チャージバック                                                                       | Stripe上で対応。特典・権利は自動的には変更しない(FR-PYMNT-008)                                                                                                                                                                                                                                                               |

スポンサー広告の強制終了における未掲載日数は、UTC-08:00時間で強制終了日と掲載開始日の遅い方から、掲載終了日までの日数とする。

## 記載上の注意

- 価格はStripeダッシュボードの設定値と一致させる。価格変更時は法的通知の改訂履歴に記録する
- 参考価格は[料金及びプラン体系](../overview/002-pricing-and-plans.md)を参照
- 事業者の電話番号を非公開にする場合、請求があれば遅滞なく開示する旨を記載する
- 章5の支払方法の列挙は、決済画面の支払方法の表示([決済の画面の文言](../design/003-text-and-copy-rules.md#決済の画面の文言))と一致させる。決済画面は見出しのアンカーを付けずに`/legal`へリンクするため、見出しを改訂しても決済画面からのリンクは切れない
