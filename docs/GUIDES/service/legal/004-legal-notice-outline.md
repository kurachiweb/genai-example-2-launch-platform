# 法的通知の大枠

管理者が管理画面で編集する法的通知ページ(FR-ADMAG-006)の構成。特定商取引法に基づく表記(LR-002)を中心に、事業者としての法定表示をまとめる。事業者情報の値は本書に書かず、管理画面で入力する。

## 章立て

| 章 | タイトル                             | 記載事項                                                                                                   |
| -- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 1  | 事業者情報                           | 事業者名(氏名または名称)、所在地(物理的郵送先住所)、電話番号(請求があれば遅滞なく開示する旨でも可)、メールアドレスまたは問い合わせフォーム、代表者または運営責任者 |
| 2  | 販売価格                             | Ultras月額、Weekトーナメント参加費、Yearトーナメント参加費、スポンサー広告の1日単価(Silver/Gold/Legend)。全てUSD表示、税込みか否か。各申し込み画面に表示する旨 |
| 3  | 商品代金以外の必要料金               | 通信費は利用者負担、為替手数料はカード会社の定めによる旨                                                   |
| 4  | 支払方法・時期                       | Stripeを通じたクレジットカード等、申し込み時に決済。Ultrasは毎月の更新日に自動決済                          |
| 5  | 役務の提供時期                       | 決済完了後直ちに提供(Ultras特典・トーナメント参加資格)、スポンサー広告は選択した掲載期間                    |
| 6  | 返金・キャンセル                     | 後述の「返金ポリシー」                                                                                     |
| 7  | 定期課金(Ultras)の条件               | 月額、自動更新、解約はいつでも可能で当該課金期間末まで特典継続、日割り返金なし、支払い失敗時の特典終了      |
| 8  | 動作環境                             | モダンWebブラウザ(Chrome・Firefox・Safari・Edgeの最新版)                                                    |
| 9  | 通知メールの送信者情報               | 特定電子メール法・CAN-SPAM法に基づく送信者名・住所・連絡先(通知メール末尾と同じ内容)                        |
| 10 | 準拠法・管轄                         | 日本法、東京地方裁判所                                                                                     |

## 返金ポリシー

| 状況                                                       | 対応                                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------ |
| 原則                                                       | デジタル役務の性質上、決済完了後の返金は行わない                         |
| 二重決済                                                   | 重複分を返金する                                                         |
| システム障害により役務を提供できなかった                   | 返金する(例: 決済したがトーナメント参加資格が付与されなかった)           |
| トーナメントの不戦勝・不戦敗・両者敗北                     | 参加資格は付与済みのため返金しない                                       |
| ユーザー停止・プロダクト非公開化に伴う参加資格・広告の停止 | 返金しない(規約違反による)                                               |
| 管理者によるスポンサー広告の強制終了(規約違反以外の理由)   | 未掲載日数分を管理者の判断で返金する                                     |
| Ultrasの解約                                               | 当該課金期間末まで特典を継続し、日割り返金はしない                       |
| チャージバック                                             | Stripe上で対応。特典・権利は自動的には変更しない                         |

返金はStripeダッシュボード上で管理者が手動実行し、決済履歴に返金として反映される。返金の申し出は問い合わせフォームで受け付ける。

## 記載上の注意

- 価格はStripeダッシュボードの設定値と一致させる。価格変更時は法的通知の改訂履歴に記録する
- 参考価格は[料金及びプラン体系](../overview/002-pricing-and-plans.md)を参照
- 事業者の電話番号を非公開にする場合、請求があれば遅滞なく開示する旨を記載する
