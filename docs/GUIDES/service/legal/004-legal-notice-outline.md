# 法的通知の大枠

管理者が管理画面で編集する法的通知ページ(FR-ADMAG-006)の構成。特定商取引法に基づく表記(LR-008)を中心に、事業者としての法定表示をまとめる。事業者情報の値は本書に書かず、管理画面で入力する。

## 章立て

| 章  | タイトル               | 記載事項                                                                                                                                                            |
| --- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 事業者情報             | 事業者名(氏名または名称)、所在地(物理的郵送先住所)、電話番号(請求があれば遅滞なく開示する旨でも可)、メールアドレスまたは問い合わせフォーム、代表者または運営責任者  |
| 2   | 販売価格               | Ultras月額、Weekトーナメント参加費、Yearトーナメント参加費、スポンサー広告の1日単価(Legend/Gold/Silver)。価格は税込表示である旨(LR-009)、各申し込み画面に表示する旨 |
| 3   | 商品代金以外の必要料金 | 通信費は利用者負担、為替手数料はカード会社の定めによる旨                                                                                                            |
| 4   | 支払方法・時期         | Stripeを通じてクレジットカード決済。申し込み時に決済。Ultrasは毎月の更新日に自動決済                                                                                |
| 5   | 役務の提供時期         | 決済完了後直ちに提供(Ultras特典・トーナメント参加資格)、スポンサー広告は選択した掲載期間                                                                            |
| 6   | 返金・キャンセル       | 後述の「返金ポリシー」                                                                                                                                              |
| 7   | 定期課金(Ultras)の条件 | 月額、自動更新、解約はいつでも可能で当該課金期間末まで特典継続、日割り返金なし、支払い失敗時の特典終了                                                              |
| 8   | 動作環境               | 要件定義書2.4節のクライアント要件                                                                                                                                   |
| 9   | 通知メールの送信者情報 | 特定電子メール法・CAN-SPAM法に基づく送信者名・住所・連絡先(FR-NOTIF-007の通知メール末尾と同じ内容)                                                                  |
| 10  | 準拠法・管轄           | [準拠方針の前提](001-compliance-policy.md#前提)に従う                                                                                                               |

## 返金ポリシー

| 状況                                                           | 対応                                                             |
| -------------------------------------------------------------- | ---------------------------------------------------------------- |
| 原則                                                           | デジタル役務の性質上、決済完了後の返金は行わない                 |
| 二重決済                                                       | 重複分を返金する                                                 |
| システム障害により役務を提供できなかった                       | 返金する(例: 決済したがトーナメント参加資格が付与されなかった)   |
| トーナメントの不戦勝・不戦敗・両者敗北                         | 参加資格は付与済みのため返金しない                               |
| ユーザー停止に伴う定期課金(Ultras)の特典提供停止               | 当該課金期間末までの日数分を管理者の判断で返金する               |
| ユーザー停止やプロダクト非公開化に伴うトーナメント参加資格停止 | 返金する(ユーザーの規約違反でも停止は事業者側の都合であるため)   |
| 管理者によるスポンサー広告の強制終了                           | 未掲載日数分を管理者の判断で返金する                             |
| Ultrasの解約                                                   | 当該課金期間末まで特典を継続し(FR-PPLAN-003)、日割り返金はしない |
| チャージバック                                                 | Stripe上で対応。特典・権利は自動的には変更しない(FR-PYMNT-007)   |

返金はStripeダッシュボード上で管理者が手動実行し、FR-PYMNT-005により決済履歴へ反映される。返金の申し出は問い合わせフォームで受け付ける。

スポンサー広告の強制終了における未掲載日数は、UTC-08:00時間で強制終了日と掲載開始日の遅い方から、掲載終了日までの日数とする。

## 記載上の注意

- 価格はStripeダッシュボードの設定値と一致させる。価格変更時は法的通知の改訂履歴に記録する
- 参考価格は[料金及びプラン体系](../overview/002-pricing-and-plans.md)を参照
- 事業者の電話番号を非公開にする場合、請求があれば遅滞なく開示する旨を記載する
