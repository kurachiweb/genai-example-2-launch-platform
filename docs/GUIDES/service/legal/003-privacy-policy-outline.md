# プライバシーポリシーの大枠

管理者が管理画面で編集するプライバシーポリシー(FR-ADMAG-006)に含めるべき章立てと各章の要点。個人情報保護法(日本)を基本とし、GDPR・CCPA/CPRA・LGPDが求める開示事項を併せて満たす構成とする(LR-006)。

## 章立て

| 章  | タイトル           | 要点                                                                                                                                                                                                | 根拠要件                             |
| --- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 1   | 事業者情報と連絡先 | 個人情報取扱事業者の名称・所在地・代表者、プライバシーに関する問い合わせ窓口(問い合わせフォーム)                                                                                                    | LR-006                               |
| 2   | 収集する情報       | 後述の「収集する情報の一覧」                                                                                                                                                                        | DR-001                               |
| 3   | 利用目的           | サービス提供(アカウント管理・マッチ運営・通知)、不正防止、決済、問い合わせ対応、統計(週毎の集計)、法令遵守                                                                                          | —                                    |
| 4   | 法的根拠(GDPR対応) | 契約の履行(サービス提供・決済)、正当な利益(不正防止・セキュリティ、通知メールの送信〔種類ごとに配信停止可能〕)、法的義務(決済履歴の保持)                                                            | —                                    |
| 5   | 第三者提供・委託   | 後述の「委託先の一覧」。販売・共有(CCPA/CPRAの意味での)は行わない                                                                                                                                   | DR-005、DR-007                       |
| 6   | 国外移転           | 委託先が国外に所在すること、保存場所、移転の法的根拠(標準契約条項等の該当するもの)                                                                                                                  | DR-007                               |
| 7   | 保持期間           | [準拠方針](001-compliance-policy.md)のデータ保持期間の一覧                                                                                                                                          | DR-002、DR-004、DR-008、DR-012〜017  |
| 8   | 利用者の権利       | アクセス・訂正・消去・データポータビリティ・処理の制限・異議、それぞれの行使方法(設定ページ、エクスポート、退会、問い合わせ)                                                                        | DR-002、DR-003                       |
| 9   | Cookieと解析       | [準拠方針のCookieとトラッキング](001-compliance-policy.md#cookieとトラッキング)                                                                                                                     | NFR-SECUR-001                        |
| 10  | 安全管理措置       | パスワードのハッシュ化、TLS、多要素認証、レート制限、アクセス制御、監査ログ、ログの個人情報マスキング                                                                                               | NFR-SECUR-\*、DR-008                 |
| 11  | 公開情報の範囲     | 公開プロフィール(ニックネーム・ハンドル・画像・ヘッドライン・自己紹介・外部サイト・フォロワー数・Upvote履歴)、プロダクト、コメント、Upvoteしたユーザー一覧が誰でも閲覧でき公開APIでも取得されること | FR-VOTE-010、FR-DIR-004、FR-PAPI-003 |
| 12  | 未成年者           | 18歳未満は利用できないこと、判明時のアカウント削除                                                                                                                                                  | —                                    |
| 13  | 改訂               | 改訂履歴の掲示、重要な変更の周知                                                                                                                                                                    | FR-ADMAG-007〜008                    |

## 収集する情報の一覧

| 区分                           | 項目                                                                                        | 取得方法               |
| ------------------------------ | ------------------------------------------------------------------------------------------- | ---------------------- |
| アカウント情報                 | メールアドレス、パスワード(ハッシュ)、ニックネーム、ハンドル、登録日時                      | ユーザー入力           |
| プロフィール                   | プロフィール画像、ヘッドライン、自己紹介、外部WebサイトURL                                  | ユーザー入力(任意)     |
| 投稿コンテンツ                 | プロダクト情報・画像、コメント、評価、Upvote、フォロー、通報、問い合わせと添付ファイル      | ユーザー入力           |
| 未ログインユーザーの問い合わせ | ニックネーム(25文字以内)、連絡先メールアドレス                                              | ユーザー入力           |
| 未ログインユーザーの通報       | 連絡先メールアドレス(著作権侵害カテゴリ選択時のみ)                                          | ユーザー入力           |
| 決済情報                       | Stripeの取引ID、金額、日時、ステータス(カード番号等はStripeのみが保持)                      | Stripe Webhook         |
| 認証・セキュリティ             | セッション識別子、端末情報(User-Agent)、最終利用日時、TOTP設定、ログイン試行の失敗回数      | 自動取得               |
| アクセス情報                   | IPアドレス(レート制限のためハッシュ化して一時保持、ログではマスキング)、リクエストログ(7日) | 自動取得               |
| メール配信情報                 | 通知設定、配信停止トークン(ハッシュ)、バウンス・苦情の記録                                  | ユーザー設定・配信結果 |
| 判定結果                       | 使い捨てメールアドレスの判定フラグ                                                          | 外部APIによる自動判定  |

画像のExif情報(位置情報等)は配信時に除去する(DR-006)。原本には残るが、原本は配信されない。

## 委託先の一覧

| 委託先                            | 目的                                                              | 渡す情報                                                       |
| --------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------- |
| Cloudflare                        | ホスティング、データベース、ストレージ、メール送信、bot対策、解析 | サービス上の全データ(暗号化通信・保存)                         |
| Stripe                            | 決済処理                                                          | メールアドレス、決済内容(カード情報はStripeが直接取得、DR-005) |
| Amazon Web Services(Rekognition)  | 画像の自動判定                                                    | アップロード画像(縮小版、一時送信)                             |
| Google Cloud(Natural Language AI) | 検索キーワード抽出                                                | プロダクト名・タグライン・説明文、ヘルプ記事(一時送信)         |
| Sentry                            | エラートラッキング・性能計測                                      | エラー情報・リクエストメタデータ(IPアドレス除去)               |
| DISIFY                            | 使い捨てメールアドレス判定                                        | メールアドレスのドメイン部(ローカル部はダミー)                 |
| Have I Been Pwned                 | 漏洩パスワード照合                                                | パスワードハッシュの先頭5文字のみ                              |

ユーザーの物理削除後もStripe内で保持するデータは[データ主体の権利への対応](001-compliance-policy.md#データ主体の権利への対応lr-006)を参照

## 記載上の注意

- 保存場所・リージョンはインフラ構成を正とし、ポリシー本文には「変更時に改訂履歴で告知する」旨を含める
- 公開API経由で第三者がユーザーの公開情報を取得できることを明記し、利用規約の公開API条項と整合させる
- 通知メールの配信停止はいつでも可能であること、[配信停止の対象外](001-compliance-policy.md#通知メールのオプトアウトlr-005)のメールがあることを明記する
