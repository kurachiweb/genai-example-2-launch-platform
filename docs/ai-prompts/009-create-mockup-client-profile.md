`mockups`アプリにて、利用者側公開プロフィールページのデザインモックアップを作ってください。
デザインを考えるために、`README.md`の要件定義書や`docs/GUIDES/service`ディレクトリ内のドキュメントを一通り読み、方針決定や判断に悩む点の解決のため数十回私に質問してください。
作成済みのモックアップ画面に合わせるため次の指示に従ってください。

- デザイン/タイポグラフィ/UI/UXは[トップページモックアップ](../../mockups/src/routes/client/top/index.tsx)・[ディレクトリモックアップ](../../mockups/src/routes/client/p/index.tsx)・[プロダクト詳細モックアップ](../../mockups/src/routes/client/p/$handle/index.tsx)のテイストに合わせてください。
- モックアップ内の、ユーザーが入力する内容を模した仮のテキストは英語で、短い/長い文章、長い英単語を交えた多様なものを生成してください。
- モックアップ内の、本来ユーザーがアップロードする画像の位置には、ユーザープロフィール画像やプロダクトロゴ及びスクリーンショット等に似せた3色以上のSVGアートを表示してください。
- ダークモード切り替えも実装し、`prefers-reduced-motion`などアクセシビリティも考慮してください。

ただし、トップページと異なりスポンサー広告は表示しないでください。

参考：`docs/GUIDES/service/design/002-page-layouts.md`の「ユーザー公開プロフィール(`/@{handle}`)」セクション

【表示する状態一覧】
利用者側プロダクト詳細ページ同様、URL内のクエリパラメータ及び`position: fixed`で右下に表示する状態切り替えラジオボタン群(折りたたみ可能)により、以下の状態を切り替えて画面内で起こりうるあらゆるケースをカバーすること。なおタブの選択と一覧の続きの読み込みはこのリストには含めず、ページ内の操作で切り替える。本番でタブの選択をURLクエリに保持する場合は、状態切り替え用のクエリキーと重複させない。

- ユーザーログイン状態
  - 未ログイン
  - ログイン済
  - ログイン済(メールアドレス未確認)
  - ログイン済(このプロフィールの本人) ... 未掲載のプロダクトには本人にだけ表示されている旨を示す
- プロフィールの公開状態
  - 公開中
  - 停止中 ... 本人には停止中である旨と問い合わせへの導線を表示し、ローンチしたプロダクトはリンクしない
  - 退会済み・存在しない ... 閲覧者を問わず同一の404表示とし、トップページとディレクトリへの導線を添える
- プロフィールの入力状況
  - 全項目入力済み ... 外部Webサイトリンクを5件程度表示する
  - 必須項目のみ ... プロフィール画像はニックネームの頭文字を表示し、ヘッドライン・自己紹介・外部Webサイトリンクは区画ごと非表示。本人にはプロフィール設定への導線を添える
- フォロワー数
  - 多数(12,345人) ... 3桁区切りでレイアウトが崩れないか確認する
  - 1人
  - 0人
- ローンチしたプロダクト
  - 件数
    - 多数(30件程度) ... 1度に表示しきれない件数とし、続きの読み込みを確認できるようにする
    - 少数(3件)
    - 0件 ... 空状態。本人にはローンチ予約への導線を添える
  - 受賞バッジ
    - 無し
    - あり ... Product of the Week(1回)・Product of the Week(複数回)・Product of the WeekとProduct of the Yearのプロダクトを一覧内に混在させる
  - ローンチ回数
    - 全て1回
    - 再ローンチを重ねたプロダクトを含む ... 予選敗北・ディレクトリ掲載・Week準決勝敗退など結果の異なるローンチを重ねる
  - 進行状況
    - 全てマッチ終了済み
    - マッチ中・キックオフ予定を含む ... 再ローンチした掲載済みプロダクトを想定し、予選・トーナメントのマッチ中やキックオフ予定であることが分かるようにする
- Upvote履歴の件数(FR-VOTE-010)
  - 多数(200件程度) ... 予選・Week・Yearトーナメントのマッチを混在させ、続きの読み込みを確認できるようにする
  - 少数(3件)
  - 0件 ... 空状態。本人にはトップページの開催中マッチへの導線を添える
- Upvote履歴のプロダクトの状態
  - 全て掲載中 ... 名称からプロダクト詳細ページへ遷移
  - 未掲載とマッチ中を含む ... 予選で敗北した未掲載のプロダクトはロゴと名称を表示しリンクせず、開催中のマッチへのUpvoteはマッチ中であることを示す
- 画像の読み込み状態
  - 正常
  - 読み込み失敗または隔離中 ... プロフィール画像とロゴはニックネームや名称の頭文字を書記素単位で表示する。絵文字で始まるニックネーム・名称も混在させる
- ユーザー入力テキストの長さ
  - 標準
  - 上限に近い長さ ... 自己紹介は見出し・リスト・表・コードブロック・引用・リンクを含むマークダウンとし、長い英単語や長いURLでレイアウトの崩れを確認する
- ページの動作状態
  - 通常
  - ローディング ... スケルトン表示。アバター・ニックネーム・フォローボタン・タブ・一覧項目の形を保つ
  - タブ切り替え後の読み込み ... ヘッダーと自己紹介を保ったまま、タブの内容部分のみ読み込み中を示す
  - 取得エラー ... 再試行ボタンと問い合わせへの導線を表示し、技術的詳細は出さない
- 部分的な読み込みエラー
  - 無し
  - タブの内容の読み込み失敗 ... ヘッダーと自己紹介を保ったまま、タブ内に再試行ボタンを表示する
  - 続きの読み込み失敗 ... 表示済みの項目を保ったまま、一覧の末尾に再試行ボタンを表示する
